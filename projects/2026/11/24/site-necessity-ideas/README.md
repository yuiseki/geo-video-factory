# 同じ型で問える題材の案

「共通の型」([../README.md](../README.md)) で問える題材。2026-11-24 に自前 OSM・公的オープンデータ・ライセンス・分析ツール・映像レンダラーの実現可能性を 1 件ずつ確認した結果は [feasibility.md](feasibility.md) にまとめた。史実の記述は記憶に基づくため、着手の前に手順書の「先に史実を確かめる」を必ず通す。

見込みの書き方: 高 = 標高タイルと自前の OSM だけでほぼ足りる。中 = もう 1 つ、所在・定義の確認や前処理が要る。低 = 要のデータが未デジタル化または未整備で作成コストが大きい。

| 案 | 問い | 量と比べる相手 | 見込み | 映像 |
|---|---|---|---|---|
| 東海道線はなぜ箱根を避けたか | 明治の東海道線は、国府津から御殿場を回って沼津へ出た (今の御殿場線)。箱根を越える経路と比べて、最大の勾配と登りの合計はどれだけ違うか | 経路に沿った勾配。勾配の上限つきの最小コスト経路が御殿場まわりを選ぶか | 高。旧東海道と同じ標高と OSM 御殿場線あり。勾配上限コストとトンネル上 DEM 補間が要る (N05 は非商用制限で不可) | 3D 地形、街道と鉄道の 2 本の線 |
| 幹線は中山道か東海道か | 東西の幹線鉄道は、初め中山道の経路で計画され、のちに東海道へ変えられた。2 つの経路の登りの合計と最大の勾配は、どれだけ違うか | 経路ごとの縦断の図。碓氷峠の急勾配が数字で出るか | 中。OSM 中山道は 9 リレーションに分散し途切れあり。鉄道計画線の定義と広域 DEM の解像度設計が要る | 縦断の動く図と 3D 地形 |
| 開港場はなぜ神奈川宿でなく横浜か | 横浜の居留地は、東海道の神奈川宿からどれだけ歩いて遠く、水でどれだけ囲まれていたか | 東海道からの歩行時間、出入り口の数 (橋)。神奈川宿の周りの候補地と比べる | 中。今昔マップはタイル複製不可のため、NARO 迅速測図 (CC BY 2.1 JP) と地理院「明治期の低湿地」を使い、1859 年との約 20 年差は古地図トレースで補う | 2D の地図と年代別の重ね |
| 石見銀山の街道 | 世界遺産の構成資産の 2 本の街道 (鞆ヶ浦道、温泉津沖泊道) は、銀山から港への歩く時間の最小の経路か | Tobler の最小の経路と帯。2 つの港の時間の差 | 低〜中 (下方修正)。自前 Overpass に街道の線・名前付き徒歩道が 0 件のため、線比較には公式地図からのトレースが要る。2 港の歩行時間比較に絞れば高 | 3D 地形、旧東海道と同じ絵 |
| 橋野鉄鉱山と釜石 | 高炉の場所は、鉄鉱石の採掘場、木炭の森、送風の水車を回す川の 3 つに近いか | 採掘場からの歩行時間、川の集水面積。同じ谷のほかの地点の順位 | 中。高炉と川は OSM あり。採掘場は非公開域だが推薦書等の図から座標読取可。木炭の森は定量データが無いため採掘場×川の 2 軸に絞る | 3D 地形と谷の断面 |
| 琵琶湖疏水の線 | 疏水は、琵琶湖と蹴上の落差をどう使ったか。線は等高線に沿うか、トンネルはどこで山を抜くか | 線に沿った標高の縦断。蹴上の落差が公表の値と合うか | 高。自前 OSM に第 1・第 2 疏水・蹴上インクライン・トンネル 27 way まで収録済。トンネル上の地表と水面の 2 線縦断で見せる | 縦断の動く図、3D 地形 |
| 明治の洋式灯台 | 神子元島、観音埼、石廊埼などの灯台は、航路のどこまでを照らすか。灯の高さから出る水平線の距離は、公表の光達距離と合うか | 灯の高さと地球の丸みから出る見える海域。灯台どうしの重なりと空白 | 中〜高 (可視域スキル後)。OSM の属性は欠損が多いため海しる API v3・灯台表から取る。地理的光達距離と光学的光達距離の区別が要る | 地球儀から寄る、海の上の円 |
| 品川台場の配置 | 台場の砲の射程の円は、江戸湾の奥への航路をふさぐか | 射程の円と、船の通れる深さの海域の重なり | 低。現存は第 3・第 6 のみ。明治海図は NDL・海図アーカイブに画像はあるが水深の数値データが存在せず手作業デジタイズが要る | 2D の地図、円の重なり |
| 足尾の鉱毒はどこへ流れたか | 足尾から渡良瀬川を下った水は、どの町を通り、どこで広がるか。谷中村 (今の遊水地) は、流れの集まる低い所か | `terrain-hydrology` の流れの線と集水域、HAND。遊水地の範囲と比べる | 中〜高。Geoshape 1889 年栃木・群馬 GeoJSON (CC BY 4.0) 取得可。ただし現代 DEM に草木ダム・遊水地堤防・谷中湖掘削があるため迅速測図・低湿地と併用して分離設計が要る | 3D 地形の上を水の線が下る |
| 富岡製糸場の立地 | 富岡は、繭の産地、水、燃料、広い土地の条件をどこまで満たすか | 川の集水面積、平らな土地の広さ。周りの町と比べる | 低〜中。Geoshape 1889 年群馬 336 町村 GeoJSON (CC BY 4.0) は取得可。明治初期の郡別繭統計は NDL 画像のみで、群馬県内十数郡の転記要否で決まる | 2D のコロプレス |

## 先に進めるなら

- 道具追加ゼロですぐ着手できるのは「琵琶湖疏水の線」（詳細は [feasibility.md](feasibility.md)）。
- 旧東海道の箱根と同じ範囲・同じ動画の続編として進められるのは「東海道線はなぜ箱根を避けたか」（勾配上限コストとトンネル補間を足す）。
- `terrain-hydrology` と 1889 年 GeoJSON・迅速測図で進められるのは「足尾の鉱毒はどこへ流れたか」（現代堤防の扱いを計画で先に切る）。
- 伊豆企画で可視域のスキルができたあとは「明治の洋式灯台」。下田の沖の神子元島灯台は、伊豆の企画とつながる。
