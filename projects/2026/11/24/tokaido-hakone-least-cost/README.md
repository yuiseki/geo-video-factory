# 旧東海道の箱根越えは、歩く時間の最小の経路か

## 概要

- 問い: 小田原宿から三島宿まで、標高の上を Tobler の歩行関数で歩くと、時間の最小の経路は旧東海道 (箱根宿を通る道) に重なるか。旧東海道を歩く時間は、最小の時間よりどれだけ長いか。
- なぜこの区間か: 渡し (海、橋の無い川) が無く、山越えで地形が効くはずの区間。北に足柄峠 (古代の東海道、のちの御殿場まわりの鉄道) という別の道があり、「なぜ箱根か」という対比が立つ。
- 見せ場の見込み: 3D 地形の上に、最小の時間の帯 (1.05 倍、1.10 倍、1.20 倍以内で通れる範囲) が広がり、その中を旧街道の線が通るか外れるかを見せる。外れる区間で、関所、宿場、芦ノ湖、石畳といった地形以外の理由に話をつなぐ。
- 答えは分析が出すまで分からない。重なる、外れる、のどちらでも動画になるように組む。
