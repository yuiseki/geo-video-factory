# 下田の見張所と韮山反射炉は、なぜそこにあるのか

## 概要

幕末の伊豆には、外国船に備えた施設がまとまってある。その立地を、地形から計算できる量で確かめる。

- 問い 1 (下田の見張所): 見張所の場所は、周りの岬や山のすべての地点と比べて、下田湾の湾口と外洋の航路を広く見渡せる場所か。奉行所まで早く知らせられる場所か。
- 問い 2 (韮山反射炉): 反射炉の場所は、海から見えず、上陸できる浜から歩いて遠く、砲身をくり抜く水車を回せる川のそばにあるか。同じ条件を満たす場所は、伊豆にどれだけあるか。
- 2 つをつなぐ話: 反射炉は最初は下田で着工され、ペリー艦隊の乗員が敷地に入ったため韮山へ移された、と伝えられる。これは記憶に基づく記述で、未確認。確かめられれば、「下田の敷地は条件を満たさず、韮山は満たす」という前後の比較がそのまま検証になる。
- 韮山反射炉は世界遺産「明治日本の産業革命遺産」の構成資産。同じ型をほかの構成資産へ広げる入口になる。

答えは分析が出すまで分からない。条件を満たす場所がほかに多くあれば、「地形の必然」ではなく「江川英龍の代官所が韮山にあった」という人の理由が前に出る。それも動画になる。
