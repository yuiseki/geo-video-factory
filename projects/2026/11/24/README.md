# 2026-11-24: 地形から問う街道と史跡

## 共通の型

1. 立地や経路の理由として語られる条件を、地形から計算できる量に直す (歩く時間、海から見えるか、集水面積、勾配)。
2. 実際の場所だけでなく、周りのすべての場所を同じ量で並べる。実際の場所が何番目に来るかが答えになる。
3. 結果を見る前に、外れたと言う条件を書く。外れたら外れたと報告する。外れは、地形以外の理由 (政治、所有、人、技術) を調べる入口になり、動画の山場にもなる。
4. 史実 (いつ、誰が、なぜと書き残したか) は、分析とは別に一次資料か自治体・文化庁の資料で確かめ、出典を控える。記憶で書かない。

## 共通の決まり

- 分析は GeoAI-master-skills の `AGENTS.md` と各スキルの `SKILL.md` に従う。計画 (`EXPERIMENT_PLAN.md`) を流す前に書き、流した後に書き直さない。
- 動画はこのリポジトリの `AGENTS.md` と `geo-video-production` に従う。
- OSM のデータは `*.yuiseki.net` の自前のサービスから取る。公開の OSM サーバーを呼ばない。
- 実データを読む実行は、ホストの資源制限の規則に従う。
- 現代の標高、現代の道路に沿った線で過去を論じていることを、報告と画面の両方で断る。
