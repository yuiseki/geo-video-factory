# plateau-reality-view: PLATEAU++ と実写真から作る生成的ワールドモデルの実験

Tesla FSD v15 の **Reality View**（車載マルチカメラ映像から条件付き Mean-Flow モデルで三人称の立体的な周辺映像をリアルタイム生成する仕組み）に着想を得て、このリポジトリの資産（`PLATEAU++`、配置済み実写真、`packages/pipeline/world_model`）の上で**暗黙的・生成的な都市ワールドモデル**が成立するかを検証する実験プロジェクトです。

具体的な段階別の作業手順、試行錯誤の分岐条件、撤退基準の詳細は [PLAN.md](PLAN.md) に定めます。実験を回す前に [PLAN.md](PLAN.md) の基準を固定し、結果を見てから合格条件を緩めません。

---

## 1. 解きたい問題と、既存の `world_model` との違い

現行の [packages/pipeline/world_model](../../../../../packages/pipeline/world_model/README.md) は、PLATEAU の三角形メッシュを固定し、姿勢を合わせた多数の実写真から面ごとのテクスチャ（`atlas.png`）を逆算して Blender で描く**明示的幾何＋逆問題**のパイプラインです。幾何の正確さと実写看板の忠実度が高い反面、次の限界があります。

1. **未観測面の穴 (`seen.png == 0`)**: 写真が写していない裏通り・高所・遮蔽物の裏が、単調な頂点色や灰色の面のまま残る。
2. **浅い視線角の引き伸ばし (`min_cos = 0.12`)**: 交差点から横の通りへ入った瞬間など、浅い角度でしか写っていない壁の数画素が何メートルにも引き伸ばされて斜めの縞になる。
3. **地上付近（0〜2.5 m）のにじみと平面貼り付き**: 人物・車両を LaMa で消した跡のぼやけた帯や、壁・路面に絵として貼り付いた街路樹・信号柱が、カメラを進めると折れ曲がって見える。
4. **視点移動に伴う質感の不連続**: 観測密度の高い正面から少し外れただけで、急に「写真」から「粗い箱」へ質感が落ちる。

一方、Tesla Reality View はゲームエンジン的なポリゴン描画を捨て、**視覚エンコーダの特徴トークン＋直前の生成フレーム（ノイズ付加）から、条件付き Mean-Flow モデルで短い動画チャンクを直接デノイズ生成（pixels-in, pixels-out）** することで、滑らかで一貫した三人称俯瞰映像を得ています。

この実験では、「幾何の骨格（PLATEAU++）と実写真の観測は活かしつつ、描画または未観測・劣化領域の統合を暗黙的・生成的モデルに担わせることで、自由視点（特に地上〜高さ 30 m の斜め俯瞰・追従視点）の破綻を消せるか」を確かめます。

## 2. 実現可能性の整理（何を捨て、何を試すか）

### 最初から不可能として捨てること

Tesla と同じ「生映像だけを入力に、3D 幾何も外観もゼロから汎用学習する 1B 級基盤ワールドモデルのスクラッチ学習」は行いません。

- **データ構造の差**: Tesla は同期された車載 8 カメラの連続走行映像を数百万時間持つのに対し、手元にあるのは静止画カタログ（渋谷でも約 2,300 枚、1 地点あたり数枚〜約 100 枚）であり、連続フレームの運動手がかりが無い。
- **計算資源の差**: 1B クラスの動画 DiT / MeanFlow をゼロから事前学習するには数千 GPU 日規模の計算が要り、単一ノードの計算資源では収束しない。

### このリポジトリの資産で戦える 3 つのアプローチ

車載カメラ単体と違い、このリポジトリには **全国規模のメートル単位の都市形状（`PLATEAU++`）**、**高速な深度ラスタライザ（`raster.c`）**、**位置合わせ・人物除去済みの実写真と観測マスク（`seen.png`）** がすでにあります。これらを強い事前条件として使う 3 段階のアプローチを比較・検証します。

| アプローチ | 仕組み（Tesla Reality View との対応） | 学習コスト | 推論速度 | 主なリスク |
|---|---|---|---|---|
| **経路 A: ゼロ学習・G-Buffer 条件付き動画生成** | `PLATEAU++` 粗描画＋深度・法線＋近傍実写真参照＋前チャンク末尾フレームを、事前学習済みの制御付き動画モデル（Apache-2.0 の Wan 系 Control / VACE 等）へ渡してチャンク自己回帰生成 | **なし**（ゼロショット） | 遅い（20〜30 NFE） | チャンク境界での色調ドリフト、日本の看板の文字化け、VRAM 逼迫 |
| **経路 B: 自己教師ペアによる少数ステップ生成修復器（本命）** | `world_model` から特定の写真を抜いた粗描画＋深度＋`seen` マスクを入力 $X$、抜いた実写真（人物除去済み）を正解 $Y$ とするペアを自動生成し、1〜4 NFE の条件付き Flow / MeanFlow 修復器（Difix3D+ 型）を学習。必要に応じ生成ビューを 3D アトラス / 3DGS へ書き戻す | **低〜中**（単一 GPU で数時間〜1日） | 速い（1〜4 NFE、書き戻せば 1.5 秒/枚） | カメラ位置合わせ誤差（数 px〜数十 px）による学習ボケ、フレーム間の微細なちらつき |
| **経路 C: 地区特化・小型 Conditional Mean-Flow ワールドモデル（挑戦枠）** | 近傍写真群の固定視覚特徴（DINOv2 等）＋目標カメラの Plücker 光線＋ノイズを加えた前フレーム潜在から、1〜2 NFE で次チャンクを直接出す小型潜在 DiT（100M〜300M）を、渋谷 1 地区の合成・実写軌道で MeanFlow 蒸留 | **中〜高**（潜在キャッシュ前提で十数〜数十 GPU 時間） | **最速**（メッシュ描画不要、1〜2 NFE） | 別の街へゼロショット転移できない、高周波ディテール（細かい看板）の消失、JVP 学習のメモリ制約 |

実験はコストの低い **経路 A → 経路 B → 経路 C** の順にゲートを設けて進め、途中の計測結果に応じて分岐または撤退します（[PLAN.md](PLAN.md) 参照）。

## 3. ライセンス・公開・再現性の拘束条件

このプロジェクトもリポジトリ全体の規則（[AGENTS.md](../../../../../AGENTS.md)）および生成モデルの運用方針（[generation_model_licences.md](../../20/liminal-space-city-walk-with-bgm/research/generation_model_licences.md)）に従います。

1. **モデルのライセンス**:
   - 採用候補は商用利用・改変・派生物公開と矛盾しないオープンライセンス（**Apache-2.0、MIT、BSD、CreativeML Open RAIL++-M**）に限る。
   - 非商用限定ライセンス（FLUX.1-dev 等）や、年商上限・独自利用制限により CC BY-SA での映像公開や再現手順の共有に疑義が残る重みは本編成果物に使わない。新しいモデルを試す前に、ライセンス本文・配布元・コミット・SHA-256 を `models_manifest.json`（または文書）に控える。
   - モデルの重み（元の重み・LoRA・学習済みチェックポイント）はリポジトリに含めず、再配布もしない。
2. **写真の来歴とブロックリスト**:
   - 学習ペアや参照特徴に使う写真は必ず `packages/pipeline/photos/photo_guard.py` を通し、`photo_blocklist.tsv` に載った写真（CC BY-SA や権利未確定の重複画像）を除外する。
3. **環境非依存の記述**:
   - 特定の機械のパス、ローカルホスト名、資格情報をコードや文書に書かない。推論サーバー URL やキャッシュ場所は環境変数（`$COMFY_URL`、`$GEO_VIDEO_CACHE`、`$OVERPASS_URL` 等）または CLI 引数で渡す。
   - 実データを読む処理・学習・描画は、すべて**ホストの資源制限の規則**に従って CPU・メモリ・並列数に上限を掛けて実行する。
4. **版管理と使い捨て出力**:
   - 書き出しや学習ログは `out/`（git 管理外）へ出し、ファイル名に版番号（`v2` など）を付けない。版は git のコミットで表す。

## 4. 撤退基準（要約）

次のいずれかに該当した時点で「現時点の計算資源・公開モデル・手元データでは実用的な構築が不可能、または既存の明示的パイプラインに対する優位性がない」と判断し、サンクコストを追わずに実験を凍結します（具体的な数値閾値は [PLAN.md](PLAN.md) 第 5 節）。

- **R1（計算資源の限界）**: 最小構成（`832×480` 相当、1〜4 NFE または量子化適用後）でも推論が 1 フレームあたり 5 秒を超える、または 1 地区の学習が単一ホストの資源制限下で 24 GPU 時間以内に収束しない。
- **R2（幾何の崩壊）**: PLATEAU の建物・空の境界に対するシルエット一致度（`skyline_iou`）が `0.85` を下回り、実在の交差点・街路構造が歪む・消える現象を制御できない。
- **R3（時間方向の破綻）**: 3 チャンク（約 10 秒）の自己回帰生成で色飽和・暗転ドリフトが起きる、または 3D 再投影ワープ誤差が既存の `world_model` より悪化し、静止建物の窓や看板が毎フレーム蠢く。
- **R4（既存手法に対する優位性不在）**: Hold-out 実写真との比較（LPIPS および等倍目視）で、既存の決定論的パイプライン（`PLATEAU++ v0.1.0` + `world_model` アトラス逆算）を上回らない、特に実写で読めていた看板の劣化が未観測面補完の利益を上回る。
