## 1. 企画概要

- **仮タイトル**
  - 本命案：**「温泉天国・伊豆の地下に眠る『昭和のゴールドラッシュ』と負の歴史」**
  - 副案：「鉱山あるところに温泉あり——南から来た火山が生んだ金と湯と悲劇」
- **テーマ**：伊豆半島の温泉と昭和期の金山開発（ゴールドラッシュ）、そして戦時統制・鉱害・災害の歴史
- **想定尺**：10〜12分（全6章構成、長尺解説動画）
- **想定話者**：ずんだもん・四国めたん（2人掛け合い解説）
- **コアメッセージ**：
  1. 伊豆半島は元々、南洋の底にあった海底火山がフィリピン海プレートに乗って北上し、本州に衝突してできた土地である。
  2. 多くの火山は現在休止中だが、地下には熱いマグマの熱源が残っており、それが日本屈指の**温泉**を湧かせている。
  3. 同じ地下の**超高温・高圧の熱水**が、岩の割れ目に金を沈殿させて**熱水鉱床（金鉱脈）**を作った。「鉱山あるところに温泉あり」は地質学的な必然である。
  4. 昭和期、戦争に伴う外貨決済のために金が急務となり、国策で「昭和のゴールドラッシュ」が起きた。しかし戦局悪化で一転して強制閉山やアルミ原料採掘への強制労働に追い込まれ、戦後も地震によるシアン化合物流出など深刻な負の歴史を残した。

## 2. 構成設計（予測符号化ベース）

`geo-video-growth-predictive-coding` の設計原則に基づき、「視聴者の強い常識（事前分布）」を呼び出してから予測誤差を立て、映像とデータで解消していく流れを組み立てる。

|---|---|---|
| **事前分布の呼び出し** | 誰もが知るイメージを先に置く | 「伊豆＝熱海・伊東・修善寺などの平和な温泉リゾート地」。温泉街や湯けむり、海岸線の美しい3D地形を見せる。 |

| **解消 1（地質）** | なぜ同じ場所にあるのか？ | フィリピン海プレートによる海底火山の北上と本州衝突の地図アニメーション。地下のマグマが温めた**熱水**が「温泉」にも「金鉱脈（熱水鉱床）」にもなる仕組みを図解。大仁鉱山では採掘中に温泉が噴出し、後の大仁温泉になった実例を示す。 |
| **予測誤差 2** | 時代の謎を立てる | 「江戸時代に栄えた伊豆の金山が、なぜ**昭和初期**に再び一斉に掘り起こされたのか？」 |

| **予測誤差 3** | 光の裏の「影」を立てる | 「しかし、この昭和のゴールドラッシュは、戦争と自然災害によって**悲劇的な結末**を迎える」 |
| **解消 3（負の歴史）** | 3つの負の歴史を地図上で追う | ① **1943年 金鉱山整備令**で国策により強制休廃止。<br>② **伊豆珪石鉱山（宇久須）**での戦時末期アルミニウム原料（明礬石）開発に伴う、中国人・朝鮮人・勤労学徒への過酷な強制労働と争議。<br>③ **持越鉱山**の1937年坑内ガス事故（48名死亡）と労働争議、そして閉山後の**1978年伊豆大島近海の地震**による鉱滓ダム決壊（シアン化合物流出）。 |
| **結び** | 全体を1つの構造に統合 | 温泉の恵みも、金の光も、地震や鉱害の影も、すべて「プレートが衝突し続ける火山の半島」という同じ大地の上で起きた出来事としてまとめる。 |

### 3.3 昭和期の金需要急増と政策転換

※企画メモにあった財務省PDF（`https://www.mof.go.jp/pri/research/seminar/fy2022/lm20220519.pdf`）を確認したところ、同資料は関野満夫『日本の戦争財政』に基づく**「敗戦後日本の巨額の戦時国債はどのように処理されたのか（戦後インフレと財産税）」**を主題とした資料であり、昭和戦前期の「産金奨励・金鉱山開発」そのものを扱った資料ではなかった。そのため、昭和期の金需要急増については以下の経済史的事実（産金法・大蔵省/日本銀行関連史料等）を別途一次資料で確認して引用する。

- **1931年（昭和6年）12月**：金輸出再禁止。管理通貨制度へ移行し、円安進行とともに国内の金買上価格が引き上げられる。
- **1932年（昭和7年）〜**：政府による産金買上げ・産金奨励の開始。満洲事変以降の軍需物資（石油・鉄鋼・工作機械等）の輸入急増に伴い、国際決済手段としての**正貨（金）の確保**が国家の死活問題となる。
- **1937年（昭和12年）**：日中戦争勃発、**「産金法」制定**（産金の政府強制買上げ・国家統制）、産金五ヶ年計画による探鉱・選鉱施設への補助金・割増金交付。これにより伊豆各地で**「昭和のゴールドラッシュ」**（土肥・持越・大仁などの拡張・再開）が加速。
- **1941年（昭和16年）12月**：太平洋戦争開戦により英米等との貿易が途絶し、外貨決済用としての金の重要性が急速に低下。
- **1943年（昭和18年）**：**「金鉱山整備令」**発令。全国の金鉱山が原則として休廃止され、資材・機械・労働力は銅・石炭・アルミニウム等の直接的な軍需鉱物増産へ強制転用された。

### 3.4 昭和期の負の歴史（災害・事故・鉱害・強制労働）

1. **持越鉱山 坑内火災・ガス事故と労働争議（1937年 / 昭和12年）**
   - 1937年3月15日、大沢郷坑で火災が発生。消火作業中に風向きが変わり坑内ガスが充満、救助隊にも被害が広がり**48名が死亡**。
   - 同年5月、会社側は「鉱況不良」を理由に従業員858人中**277人の解雇**を発表。労働争議（ストライキ）に発展し、7月に警察調停により和解。
2. **伊豆珪石鉱山（宇久須）明礬石開発における強制労働（1944〜1945年）**
   - 戦局悪化に伴う航空機用アルミニウム不足を補うため、国策（軍需省直轄・住友鉱業主導）で宇久須の明礬石開発を強行。隣の土肥金山の設備・人員も1944年6月に停止して転用。
   - 労働力として**朝鮮人約800人、中国人約200人、および勤労学徒**が動員された。食事は極めて乏しく（中国人は練り粉の塊1日1個、蛇や蛙を捕食）、結核や栄養失調による死者が多発。脱走者に対する山狩りや、1944年9月の朝鮮人労働争議（10名検挙）が発生した。製錬法も確立できず未完成のまま終戦。
3. **狩野川台風による鉱山被災（1958年 / 昭和33年）**
   - 1958年9月の狩野川台風により、狩野川流域の**大仁鉱山**（施設倒壊・社宅流失・坑内水没）や**持越鉱山**（事務所・社宅流出）が甚大な被害を受け、戦後復興していた伊豆の鉱山衰退を決定づけた。
4. **伊豆大島近海の地震と持越鉱山 鉱滓ダム決壊事件（1978年 / 昭和53年）**
   - 1978年1月14日12時24分、M7.0（震度5、東伊豆町で震度6相当）の直下型地震が発生。伊豆半島東部を中心に死者25名・負傷者211名、大規模な地滑り・断層出現をもたらした。
   - この揺れにより、水抜きが不十分だった**持越鉱山の鉱滓（こうさい）ダム（ほおずき沢鉱滓堆積場）が液状化を起こし2度にわたり決壊**（14日に約30万トン、15日に約5000トンの鉱滓が流出）。
   - 猛毒の**シアン化合物**（持越橋付近の堆積鉱滓から3.4ppm検出、魚類への影響基準は約0.5ppm以上）を含む廃水・鉱滓が持越川から狩野川を経て駿河湾へ流れ込み、川魚（アユ等）の大量死、漁業被害、下流市町村の水道水取水停止・水源切り替えという深刻な公害・災害を引き起こした。
