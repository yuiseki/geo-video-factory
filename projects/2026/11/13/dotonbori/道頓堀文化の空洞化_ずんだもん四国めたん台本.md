# 道頓堀からコスモスクエアへ、二つの未来を歩く

想定尺：約11〜13分。読み上げはずんだもん＝VOICEVOX style ID 3、四国めたん＝style ID 2。

## 台本

【導入：道頓堀の夜景。川面と看板、たこ焼きの写真】

**ずんだもん：** 大阪・道頓堀のたこ焼き屋に入ったら、店員さんはみんな外国の人に見えて、来ているお客さんも海外から。英語で注文が進んで、目の前には大阪名物のたこ焼き。そこにあるのは「大阪のたこ焼き屋」という商売のミームだけ……そんな気がしたのだ。

**四国めたん：** でも、たこ焼きは絶品だったそうね。しかも、焼きたてではなかったのにおいしかった。個人の腕だけでなく、技術や段取りが店の仕組みに落とし込まれているのかもしれないわ。

**ずんだもん：** 文化が空っぽになったのか。それとも、誰が働いても再現できるほど文化が強くなったのか。今日、道頓堀で感じたこの疑問は、少し離れた南港へ向かうと、別の形で続いていくのだ。

**四国めたん：** 目の前には、江戸時代から積み重なった道頓堀と、昭和の人が思い描いた未来を名前に残すコスモスクエアがある。過去と未来が、いまの生活圏の中で同時に動いているのね。

**ずんだもん：** まずは、道頓堀の川辺から見ていくのだ。

【場面1：川の両岸の看板。江戸時代の道頓堀図を重ねる】

**ずんだもん：** それにしても、道頓堀は川がタイムズスクエアみたいなのだ。どうして川沿いが、こんなに看板だらけになったのだ？

**四国めたん：** 道頓堀川は1615年に完成した堀川。周辺には芝居小屋が集まり、劇場街として栄えたの。水辺と娯楽の結びつきは、近年の観光ブームよりずっと古いのよ。[1]

**ずんだもん：** 川ができたころから、ここは人を楽しませる場所だったのだ。川は街の裏側ではなく、見世物の舞台だったのだ。

**四国めたん：** そして1935年、戎橋のそばに初代グリコサインが登場する。広告は商品を知らせるものだけれど、長く街にあり続けると、広告そのものが「道頓堀らしい景色」になる。大阪市もグリコサインを都市景観資源に登録しているわ。[2]

**ずんだもん：** 看板が人を呼び、人が集まるから看板の価値も上がる。商売が景色をつくって、その景色がまた商売を呼ぶのだ。

**四国めたん：** 川の上に立つと、両岸の看板を向かい合って眺められる。水面には光が映る。道頓堀川は、運河として掘られたあと、芝居を見に来る人を集める場所になり、いまは光る街を眺める場所にもなった。

**ずんだもん：** 同じ川なのに、時代ごとに使い道が足されていくのだ。最初から観光のために設計されたわけじゃないのに、結果として街全体が舞台装置みたいになっているのだ。

**四国めたん：** たこ焼きも似ているわね。味、店の動線、接客、器まで含めて、来訪者が「大阪でたこ焼きを食べた」と感じる体験をつくっている。ただ、目の前の一店舗の観察から、街全体や働く人の出自まで決めつけないようにしたいわ。

**ずんだもん：** うん。店員さんが外国の人に見えたというのは、ある日の一店舗での観察なのだ。そこから街の人みんながいなくなった、なんて結論には飛べないのだ。

**四国めたん：** それでも、国籍や母語が違う人たちが、たこ焼きを焼き、注文を受け、観光客に渡している。その場で実際に文化を担っているのは、いま働いている人たちなのよね。

**ずんだもん：** 「日本人が作っていること」が文化の条件なのか。それとも、おいしいたこ焼きがこの場所で売られ、人がその体験を持ち帰ることが大事なのか。答えは簡単じゃないけれど、少なくとも文化は、昔の姿のまま保存されるだけではないのだ。

**ずんだもん：** ところで、隅田川でも娯楽が栄えていたと聞いたことがあるのだ。

**四国めたん：** そうね。次は江戸・東京の水辺の文化を見ていきましょう。

【場面2：両国橋の浮世絵。広小路と屋台を図解】

**ずんだもん：** 江戸では、どんな人たちが集まっていたのだ？

**四国めたん：** 両国よ。明暦の大火のあと、両国橋が架けられ、橋詰には火除地として広小路が設けられた。そこに屋台や水茶屋、見世物小屋が集まり、相撲や寺社の出開帳も加わって、江戸有数の盛り場になったの。[3]

**ずんだもん：** 防災のために空けた場所が、にぎわいを生んだのだ。水辺では花火や船遊びもあったのだ？

**四国めたん：** ええ。橋の上や川岸から花火を見て、屋台で食べて、船に乗る。道頓堀と両国は同じ街ではないけれど、水辺を娯楽と商業の舞台にする発想には通じるものがあるわ。

**ずんだもん：** ただ、道頓堀は運河沿いに芝居小屋が集まり、両国は橋と広小路、回向院の興行が中心。形はそれぞれ違うのだ。

**四国めたん：** そう。二つを同じものとして扱うのではなく、川や橋が人の流れをつくり、その人の流れに飲食や興行が結びついた例として比べるといい。人は水辺に集まる。そこで何を楽しむかは、時代と土地が決めるのね。

**ずんだもん：** その近くの柳橋では、水辺の文化はどう変わったのだ？

【場面3：柳橋の古写真と現在の護岸。模式断面図】

**ずんだもん：** でも、神田川が隅田川に注ぐ柳橋のあたりは、昔の花街がなくなったのだ。

**四国めたん：** 柳橋は船宿や料亭、芸妓の文化で知られた場所。東京都は、伊勢湾台風を契機に1959年から75年にかけて隅田川に「カミソリ堤防」を整備し、高い防潮堤が人と水辺を隔てた経緯を説明しているわ。[4]

**ずんだもん：** 水害から街を守る堤防が、水辺を楽しむ商売には影響したのだ。

**四国めたん：** 台東区の観光案内も、堤防造成による景観の変化などで客足が遠のき、最後の料亭と芸妓組合が1999年に閉じたと紹介している。ただし、堤防だけを原因にするのは正確ではないわ。交通や暮らし、商売の変化も重なったと考えるべきね。[5]

**ずんだもん：** 必然だったと決めつけるより、守るための都市の仕組みが、別の価値を見えにくくした、と見るのがよさそうなのだ。

**四国めたん：** 都市の安全を守ることと、水辺の風景や仕事を保つこと。どちらも大切なのに、同じ工事が両方に同じ効果をもたらすとは限らない。東京都はその後、人が川に近づける緩やかな護岸やテラスの整備も進めているわ。[8]

**ずんだもん：** 川を遠ざけた堤防を、今度は川に近づける形に直しているのだ。都市の考え方も、時間をかけて変わっていくのだ。

**四国めたん：** 今度は、川そのものが見えなくなった新橋へ向かいましょう。

【場面4：新橋の橋名板、古地図、現在の道路をつなぐ】

**ずんだもん：** そういえば新橋って、「橋」と付くけど、本当に川に架かっていたのだ？

**四国めたん：** そう。港区の説明によると、1604年ごろ、東海道の起点を日本橋まで延ばしたころ、汐留川に架けられた橋が新橋の由来。川と橋は1964年の東京オリンピックに合わせた開発で姿を消し、親柱が残っているの。[6]

**ずんだもん：** 銀座の京橋や数寄屋橋も、昔の水路や橋の記憶を地名に残しているのだ。[7]

**四国めたん：** 道頓堀では川が街の顔として残り、柳橋では堤防が水辺との関係を変え、新橋では川そのものが都市の下に隠れた。文化は、担い手だけでなく、街の形やインフラにも支えられているのね。

**ずんだもん：** 川の記憶をたどったところで、もう一度、大阪に戻るのだ。

**四国めたん：** 道頓堀から南港へ。今度は、未来を思わせる名前を訪ねましょう。

【場面5：ニュートラムの車内から南港へ。車窓、駅名標、海辺の建物】

**ずんだもん：** ここで、今日のもう一つの発見なのだ。コスモスクエア行きのニュートラムに乗っているけれど、「ニュートラム」「コスモスクエア」って名前、昭和の未来っぽくないのだ？

**四国めたん：** たしかに、どちらも未来を指さしているみたいな名前ね。駅名を聞いただけで、白い建物とガラス張りの通路、遠くまで伸びる高架が頭に浮かぶわ。

**ずんだもん：** しかも、車両に運転士さんがいないのだ。名前だけじゃなく、乗っているものまで未来なのだ！

**四国めたん：** ニュートラムが開業したのは1981年。最初の区間は住之江公園から中ふ頭までで、当時は南港ポートタウンを結ぶ交通だったの。コスモスクエアまで最初から通じていたわけではなく、その区間は1997年に開業した。[9]

**ずんだもん：** つまり、今の「コスモスクエア行き」という乗り方の中に、1981年の南港の暮らしと、1997年に伸びた新しい街がつながっているのだ。

**四国めたん：** そして無人運転の開始は1991年。開業直後から、乗務員の添乗や監視をなくしていたわけではないの。運行を安定させたあと、段階的に無人化されたと大阪市立図書館の調査資料にあるわ。[9]

**ずんだもん：** そこは思い込みと違ったのだ。開業したその日から完全無人の未来列車だった、というわけじゃないのだ。

**四国めたん：** そうね。新しい交通システムも、使いながら安全を確かめて、日常の交通として馴染ませていった。いま乗っている私たちには当たり前の運行でも、そこに至るまでの段階があったのよ。

**ずんだもん：** 「未来の技術」って、完成した瞬間に未来じゃなくなるんじゃないのだ。毎日使えるようになったとき、未来は日常の一部になるのだ。

**四国めたん：** その電車が向かう先には、どんな未来が描かれていたのかしら。

【場面6：1980年代の計画年表と現在のコスモスクエア。ATC、海辺、ビル群】

**ずんだもん：** それに、コスモスクエアのまわりは、名前だけ先に未来だったのだ？

**四国めたん：** 咲洲など大阪臨海部の新しい都市拠点を目指した「テクノポート大阪」計画は、1983年に構想が発表され、1985年に基本構想、1988年に基本計画が策定された。国際交易、情報通信、先端技術の開発といった機能を集める構想だったの。[10]

**ずんだもん：** 昭和の終わりごろ、海沿いに未来の都市を描いていたのだ。今、電車が海へ向かって伸びているのも、その計画の一部なのだ？

**四国めたん：** 交通は暮らしのために整備されて、街の計画はその先に働く場所や交流の拠点を描いたの。ニュートラムの開業とテクノポート大阪の基本計画は、同じ時期の臨海部開発という大きな流れの中にあるわ。ただし、ニュートラム自体をテクノポート構想だけから説明できるわけではないの。先に南港ポートタウンがあり、住民の移動を支える役割があった。[9][10]

**ずんだもん：** 未来都市の絵だけじゃなく、すでに住んでいる人が使う電車でもあったのだ。

**四国めたん：** ATCは1994年に開業した。大阪市の資料は、コスモスクエア地区の当初計画が国際交易や高次の都市機能を集める方向を目指していた一方、バブル崩壊などを受けて開発が停滞し、2002年以降には計画の見直しも行われたと記録しているわ。[11]

**ずんだもん：** 未来の計画は、そのまま予定通りに現実になったわけじゃないのだ。

**四国めたん：** ええ。大きな構想は景気や社会の変化に影響される。施設ができ、交通網が伸びても、当初想定した企業や人の集まり方になるとは限らない。コスモスクエアの現在の姿には、建設されたものだけでなく、変更された計画や、これからも続くまちづくりが重なっているわ。[11]

**ずんだもん：** それでも、ATCもニュートラムも、海辺のビルも今ここにあって、ぼくたちはそれを使っている。成功か失敗かの二択で片づけるより、当初の未来像がどう日常に変わったかを見ると、面白さが増すのだ。

**四国めたん：** 「テクノポート」や「コスモスクエア」という言葉の響きには、計画を立てた人たちの期待が残っている。でも乗客にとっては、電車に乗って、目的地で降りて、用事を済ませる場所。壮大な未来が、いまは具体的な移動や仕事や買い物になっているのね。

**ずんだもん：** 未来の名前がレトロに聞こえるのは、未来が古びたからなのだ？

**四国めたん：** 名前の響きが時代をまとっているのは確かね。でも、使われ続ける交通や建物は、過去の計画が現在の生活に組み込まれた証拠でもある。懐かしさと現役が、同じ景色に並んでいるのよ。

**ずんだもん：** それじゃあ、道頓堀と南港を並べて、二つの街を見てみるのだ。

【場面7：道頓堀の看板とコスモスクエアの遠景を交互に映す】

**ずんだもん：** 道頓堀は、商売や芝居が積み重なって、あとから「大阪らしい景色」になった。コスモスクエアは、まず未来の計画を描いて、そこへ街や施設をつくっていった。ずいぶん違う出発点なのだ。

**四国めたん：** 道頓堀には、積み重ねから景観が育つ「ボトムアップ」の面がある。南港の計画には、行政や事業者が広い範囲の将来像を描く「トップダウン」の面がある。ただ、現実の街はどちらか一方だけではないわ。道頓堀にも行政の河川整備や観光政策があり、南港にも毎日通勤や通学をする人の暮らしがある。

**ずんだもん：** ひとつは古いから残った、もうひとつは新しいから失敗した、みたいな話でもないのだ。

**四国めたん：** そう。長く続く街も、時代ごとに姿を変えている。計画都市も、完成図のまま保存されているわけではない。人が住み、働き、移動することで、当初の計画を使い替えていくの。

**ずんだもん：** 今日の行動範囲の中には、江戸時代から続く娯楽の記憶も、昭和の未来都市の記憶もある。しかも、それぞれが古い展示物じゃなく、いま営業する店や、いま走る電車としてそこにあるのだ。

**四国めたん：** それが不思議で、面白いのね。道頓堀のネオンを見て、たこ焼きを買い、ニュートラムに乗ってコスモスクエアへ向かう。歴史の層を順番に博物館で見るのではなく、一日の移動の中で通り抜けている。

**四国めたん：** 最後に、この一日の発見を振り返ってみましょう。

【結び：道頓堀の水面から、柳橋、新橋の地図へ】

**ずんだもん：** 道頓堀のたこ焼き屋にあったのは、空っぽのミームだけじゃない。誰かが受け継ぎ、磨き、訪れた人に届ける仕組みも、そこにあったのだ。

**四国めたん：** ただ、街の文化が残るかどうかは、商品や働く人だけでは決まらない。川をどう使い、何を守り、誰がその場所に近づけるのか。その選択が、次の景色をつくっていくのね。

**ずんだもん：** みなさんの街にも、名前だけ残った橋や、いつの間にか見えなくなった川があるかもしれないのだ。

**四国めたん：** そして、昔に描かれた未来が今も現役で動いている場所もあるかもしれない。次に乗る電車や通り過ぎる建物の名前を、少しだけ昔の人の目で眺めてみてもいいわね。

**ずんだもん：** コスモスクエア行きのニュートラム。昭和の未来っぽい名前なのに、今日もちゃんとぼくたちを運んでくれているのだ。

- **地図素材：取得済みです。** 道頓堀、柳橋・両国、新橋、コスモスクエア駅の過去と現在の空中写真、標準地図、淡色地図を `maps/` にまとめました。年代ごとの画像と利用上の注意は同ディレクトリの `README.md` を参照してください。
- **権利：要確認の素材があります。** 保存された共有ページには歴史写真等が埋め込まれていますが、ページ上で見つかったことだけでは動画への転載許諾を確認できません。大阪市・博物館・東京都等の掲載画像も、各画像の権利表示と二次利用条件を確認してから使うのが安全です。
- **キャラクター画像：音声とは別確認です。** VOICEVOX音声は各音源規約に従いクレジット付きで利用できます。一方、ずんだもん・四国めたんの立ち絵はキャラクター利用ガイドラインが別に適用されます。台本は立ち絵なしでも字幕とオリジナル図解で成立します。
- **現行プロジェクトとの接続：既存の掛け合いレンダラーを利用できます。** `projects/2026/11/11/moyashi/flyover/` には、二人の VOICEVOX 音声、字幕、立ち絵に対応した特集動画用レンダラーと完成例があります。この Markdown 台本を使うには、セリフや映像の指定を同レンダラーのショット JSON 形式にまとめる必要があります。
