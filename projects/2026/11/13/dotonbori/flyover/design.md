# v0.1.4 以降の制作設計

## 章と編集点

- 原稿の場面見出しを唯一の章境界として、章ごとにショット JSON と音声を生成する。画面に章タイトルが残っているかどうかから境界を推測しない。v0.1.2 / v0.1.3 では写真の挿入によって「光る水辺の街」の画面見出しが置き換わったため。
- 章と章の間に、番組タイトル・章番号・章名を表示する無音のタイトルカードを入れる。カードの長さとレイアウトは共通設定に置き、音声・映像とも前後の章から独立させる。
- 各章は同じ解像度、fps、音声形式で個別に出力し、タイトルカードを挟んで結合する。結合前に各クリップの形式、長さ、欠落を検査し、完成後は再生時間と章時刻を実ファイルから生成する。
- 章生成を並列実行できるジョブ単位に分ける。並列数は設定可能にし、親の systemd scope に CPU・メモリの上限を掛ける。地理院タイルのキャッシュとリクエスト量も考慮して並列数を決める。
- 各章の音量を独立に正規化すると章間で声の大きさが変わり得る。音声の正規化は全章の音量をまとめて測定してから共通の値を適用するか、結合後に一度だけ行う。

## 再利用できる映像効果

- 場面選択と映像効果を分ける。`shot_effects.py` に地図の寄り・引き・横移動・静止、写真の移動方向、地図上のラベル生成を切り出した。地図比較・路線表示・タイトルカードにも同じ方針を広げる。
- タイトルカード、写真の寄り・引き・パン、地図上のラベル、路線、昔と今の比較をそれぞれ独立した再利用可能な部品にする。時間・速度・開始位置・終了位置・著作権表示を入力として受け取る。
- 効果の適用前後で、同じ画像の再利用と、関連しない写真の誤用を避ける。画像一覧には対象・時代・作者・ライセンス・使用した章を記録する。

## 周辺ランドマーク

- 道頓堀は主題と一緒に、なんば駅・心斎橋駅などの位置を同じ画面に表示する。表示はカメラの縮尺と画面内の位置、ラベル同士の重なりを考慮する。
- Nominatim の importance は候補の順位付けに使い、地理的範囲、地物の種別、同名施設、台本での役割で絞る。なんばは複数の駅が近接するので、どの駅・路線を指すかを決めてから代表点を選ぶ。
- ローカル Nominatim で、なんばと心斎橋の鉄道駅候補、戎橋の候補を取得できた。検索語に「駅」を付けるとホテルが返ることがあるため、検索結果の category / type を確認する。
- 空中写真が過去の年代の場合、現代のランドマークを表示していることを画面と概要欄に明記する。

`chapter_pipeline.py` で章別並列レンダリングと結合を実装した。`title_card.py` に無音カードの生成を切り出し、道頓堀周辺に Osaka Metro のなんば駅・心斎橋駅を表示した。v0.1.4 は２並列で生成し、以降の既定値は３並列。地図比較・路線表示の共通部品化は引き続き未実施。
