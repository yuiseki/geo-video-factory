# 道頓堀とコスモスクエアの地図素材

国土地理院の年代別写真タイルを、各地点につきズーム16の2×2枚（512×512ピクセル）で取得して接合した素材です。元のタイル、画像範囲、取得URL、取得結果は `manifest.json` と各地点の `raw/` に残しています。画像は北が上です。

## 一覧

| 地点 | 一覧画像 | 取得できた年代 |
|---|---|---|
| 道頓堀・戎橋 | [画像を比較](dotonbori/一覧.jpg) | 1928年頃、1936〜42年頃、1945〜50年、1961〜69年、1974〜78年、全国最新写真 |
| 柳橋・両国橋 | [画像を比較](yanagibashi/一覧.jpg) | 1936〜42年頃、1945〜50年、1961〜69年、1974〜78年、1987〜90年、全国最新写真 |
| 新橋跡・汐留川 | [画像を比較](shimbashi/一覧.jpg) | 1936〜42年頃、1945〜50年、1961〜69年、1974〜78年、1987〜90年、全国最新写真 |
| コスモスクエア駅・咲洲 | [画像を比較](cosmosquare_station/一覧.jpg) | 1961〜69年（一部）、1974〜78年、1979〜83年、1984〜86年、全国最新写真 |

各地点について、同じ範囲の標準地図と淡色地図も保存しています。道頓堀は [標準](dotonbori/std.png)・[淡色](dotonbori/pale.png)、柳橋は [標準](yanagibashi/std.png)・[淡色](yanagibashi/pale.png)、新橋は [標準](shimbashi/std.png)・[淡色](shimbashi/pale.png)、コスモスクエア駅は [標準](cosmosquare_station/std.png)・[淡色](cosmosquare_station/pale.png) です。

「全国最新写真」は複数の時期の画像をつないだものです。各年代の表記も国土地理院のレイヤーの期間であり、地点ごとの撮影日を確定したものではありません。特に1961〜69年の新橋の写真を、汐留川が埋め立てられた前後の特定の年と決めつけないでください。

コスモスクエアの1961〜69年は画像の欠けがあります。1945〜50年と1987〜90年のタイルは、取得した駅周辺で404でした。**画像がないことだけでは当時の地形や海岸線を判断できません。** 検索で返された駅名の座標が駅より北の沖合を指していたため、最初に取得した画像を `cosmosquare/` に参考として残し、所在地と照合した駅周辺を `cosmosquare_station/` に収めました。駅の中心座標は概略です。

## 動画の場面候補

- **道頓堀の変化**：[1928年頃](dotonbori/ort_1928.png) → [1961〜69年](dotonbori/ort_old10.png) → [全国最新写真](dotonbori/seamlessphoto.png)。1928年頃の画像には端の欠けがあり、全体にコントラストが低めです。
- **柳橋と両国**：[1945〜50年](yanagibashi/ort_USA10.png) と [全国最新写真](yanagibashi/seamlessphoto.png)。神田川の合流部と両国橋付近を同じ範囲で比較できます。料亭の営業状況や堤防の影響は写真だけから断定せず、台本の資料と併用します。
- **新橋と汐留川**：[1936〜42年頃](shimbashi/ort_riku10.png) → [1945〜50年](shimbashi/ort_USA10.png) → [全国最新写真](shimbashi/seamlessphoto.png)。旧水路周辺の街区の変化を比較できます。河道を線で強調する際は別資料と照合してください。
- **咲洲の造成と開発**：[1974〜78年](cosmosquare_station/gazo1.png) → [1979〜83年](cosmosquare_station/gazo2.png) → [1984〜86年](cosmosquare_station/gazo3.png) → [全国最新写真](cosmosquare_station/seamlessphoto.png)。複数の写真の継ぎ目や色の違いがあります。

古い写真には位置ずれやつなぎ目があります。写真を重ねた比較で境界がずれて見えても、実際の位置変化とは限りません。暗い画素が欠損部分に使われる `gazo1`〜`gazo4` は、接合PNGではRGB各値3以下を透明化しています。水面や影の一部も透明化される可能性があるため、必要に応じて `raw/` の元JPEGも確認してください。

## 特集用レンダラーで使う場合

`projects/2026/11/11/moyashi/flyover/` の地図描画は `ort_riku10`、`ort_USA10`、`ort_old10`、`gazo1` と `seamlessphoto` を地理院タイルから直接読み込めます。`ort_1928`、`gazo2`、`gazo3` は現在のレンダラーのレイヤー一覧にはありません。これらは接合PNGをレンダラーの `assets/` 配下へコピーし、`image` オーバーレイに `manifest.json` の `bbox_west_south_east_north` を指定する方法があります。

例は、道頓堀の1928年頃のPNGを `assets/dotonbori/ort_1928.png` に置いた場合です。

```json
{
  "type": "image",
  "src": "assets/dotonbori/ort_1928.png",
  "bbox": [135.494384765625, 34.664840578219284, 135.50537109375, 34.67387626588272],
  "credit": "空中写真：国土地理院（1928年頃）を加工",
  "show": [0, 1]
}
```

今回保存した接合画像は位置と年代の確認用にも使える小範囲の素材です。画面いっぱいに拡大する場合は画質を確認し、必要に応じて範囲とズームを決めて追加取得します。地理院タイルを多数連続取得しないよう、取得範囲は必要な分に限ります。

## 出典と利用条件

- [国土地理院「地理院タイル一覧」](https://maps.gsi.go.jp/development/ichiran.html)：各レイヤーの年代、提供範囲、利用条件。
- [国土地理院「地図・空中写真閲覧サービスのヘルプ」](https://service.gsi.go.jp/map-photos/app/help)：単写真とオルソ画像の違い、撮影年月日の調べ方。
- [国土地理院「承認申請Q&A」](https://www.gsi.go.jp/LAW/2930-qa.html)：地図や写真の利用方法ごとの出典・申請の扱い。

出典表示の例：`出典：国土地理院 地理院タイル（空中写真、1945年〜1950年）を加工して作成`。`gazo1`〜`gazo4` は元データが国土画像情報なので、使用する年代とともに `国土画像情報（国土交通省）` を明示します。使うレイヤーの規約と最終的な表示方法は公開時に確認します。
