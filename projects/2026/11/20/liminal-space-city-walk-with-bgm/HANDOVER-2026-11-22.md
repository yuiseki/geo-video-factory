# 引き継ぎメモ 11/22: 実写真から人と車を消す

`HANDOVER.md` (11/21 時点、main の未コミットの作業中) の 6 節として足す内容。別のセッションの worktree から書いたため、別ファイルにした。`HANDOVER.md` へ移したら消してよい。

## 方針

生成画像を見本にせず、CC0 / CC BY の夜の交差点の写真 (`flyover/assets/photos/crossing_night_cc0/crossing_night/`, 22 枚) を正本にして、人と車だけを消す。看板の差し替えと Blender での投影は、この後の工程。

## 実装と出力

- 実装: `packages/pipeline/people_removal.py` (テストあり)。手順と、誤検出を落とす規則は `.agents/skills/geo-video-materials/references/people-removal.md`。
  - SAM 3.1 (ComfyUI) で人、看板・画面、車を別々に検出し、規則で組み合わせたマスクを作る。
  - そのマスクを LaMa (長辺 1024 px) で塗る。
- 出力: `flyover/out/people_removal_cc0/crossing_night_v6/` が現行。中身は `<id>_nopeople.png`、マスク、SAM の生の層。v3〜v5 は比較用の旧版。

044 に残った白い車は、SAM が看板・画面としても拾ったため規則で落ちた (`people-removal.md` の検品の節)。`mask_additions.json` に手で箱を足し、`remix --add` で塗り直した。現行は `night_v2/044_*_nopeople.png` (車は消え、路面のヘッドライトの光だけ残る。街灯の光に見える)。

センター街の入口は、手前の群衆が大きい写真しかなく、自動では路面が作れない。センター街の区間は、地上の別の写真を探すか、路面を 3D で作り写真は看板の帯 (上半分) だけ使う、のどちらかが要る。

## 写真だけで歩く下書き (photo-walk v0.1.0)

Blender で投影する前に、並び、間、写真が通常の速さと音楽に耐えるかを見るための下書き。`photo_walk.py <flyover> <版>` で書き出す (ffmpeg だけで動く。既存の版は上書きしない)。

- 出力: `flyover/out/photo-walk-v0.1.0/photo-walk-v0.1.0.mp4` (57.5 秒、1280×720、24fps、-13.9 LUFS)。使った写真の一覧は同じ場所の `shots.txt`、概要欄に貼る出典は `credits.txt` (v0.3.0 から。`credits_people_removed.json` から作る)。
- 14 枚を 5.5 秒ずつ、1.5 秒のクロスフェードでつなぎ、8% だけゆっくり寄る (一歩進む感じ)。色調は v1.0.0 と同じ系統 (色ずれ、紫〜青、周辺減光、粒子)。BGM は `vaporwave_mallsoft.wav` (自作の合成) をループ。
- 順: 交差点の路面 (262, 138, 305, 212) → 交差点の中で見上げる (199, 288, 278, 068, 308) → 交差点を出る (118) → 通り (117, 267, 190) → 並木の坂で暗転 (044)。
- 見えた課題: 288 は車の光跡が流れていて「誰もいない」と食い違う。センター街の区間がまだない。

v0.3.1 (現行): `flyover/out/photo-walk-v0.3.1/photo-walk-v0.3.1.mp4`。v0.3.0 と同じ並びで、寄りを Pillow で小数の位置に描いた。ffmpeg の zoompan は整数の画素で切り出すため、ゆっくりした寄りがガタつく。時間方向の 2 階差分 (動きの滑らかさ) は完成動画で 2.80 → 0.81。

v0.3.0: `flyover/out/photo-walk-v0.3.0/photo-walk-v0.3.0.mp4` (18 枚、73.5 秒、-13.8 LUFS)。交差点の角に立つ 220 で始め、交差点の中に 147 を足した。

v0.2.1: `flyover/out/photo-walk-v0.2.1/photo-walk-v0.2.1.mp4` (65.5 秒、-13.8 LUFS)。288 を外し、交差点で見上げた後にセンター街の 3 枚 (132 → 129 → 139) を入れた。順: 交差点の路面 → 見上げる → センター街 → H&M 前 → 道玄坂の通り → 並木の坂で暗転。v0.2.0 は 139 の店内に人が残っていた版。

## 残っていること

1. rawpixel の 3 枚 (072/073/074): Openverse API (`/v1/images/<openverse_id>/`) の記録は 3 枚とも CC0 1.0 (11/22 確認、作者名なし)。rawpixel のページ自体は自動取得で 403 になり、ページ上の表記は未確認。11/23 にアプリ内のブラウザで開くと、Cloudflare の人間確認 (チェックボックス) が出た。エージェントは通らないので、公開前に人が自分のブラウザで 072 (`rawpixel.com/image/5917595`) のページを一度見る。使う 3 枚のうち rawpixel は 072 だけ (073/074 は使わない)。
2. 068 は解像度が低い。278/279 と 138/139 は、それぞれほぼ同じ場面。
3. 出典: 22 枚の作者、取得元、改変を `credits_people_removed.json` に書いた。22 枚とも取得元の記録で CC0 だった (Commons の extmetadata と Openverse API)。`credits.json` へ統合するのは未了。CC BY の 018 (Espen Faugstad, CC BY 2.0) は別の写真群で、この 22 枚には入っていない。
4. 看板の差し替え (試作): `sign_regions.py` で 4 隅を取り、`sign_replace.py` で替えた (`crossing_night_v6/<id>_nosigns.png`, 8 枚)。曲面の画面は半分しか替わらず、店先が灰色の板になり、模様も仮置きの箱に見える。替える看板の選択と絵は人が決める。
5. 動きでの確認: `flyover/out/people_removal_cc0/preview_v6.mp4` (8 枚を 4 秒ずつ寄る、25 秒、音なし)。
6. Blender での投影には、交差点の写真ごとのカメラ合わせ (対応点の手入力) が要る。`flyover/out/blender-spike-v01/fit3_result.json` は別の写真 (018/020/016) のもの。
