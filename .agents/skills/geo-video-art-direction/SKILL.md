# 地理動画のアートディレクション

地理動画の 1 画面を「見出し＋均等カード＋右欄」の定型に押し込めず、**主図の占有・文字の造形・情報密度の偏り・時間軸の緩急**から設計し、描画後の実ピクセルで検品する。個別の重ね物・素材・カメラ技法は `geo-video-visuals` や `geo-video-camera` に任せ、本スキルは画面全体の構成基準と検品を担う。

## 読む資料

- 作品ごとのスタイル仕様書（`STYLE.md`）のテンプレートと運用： [references/style-sheet.md](references/style-sheet.md)
- 構図・文字造形・情報密度・時間の設計基準： [references/composition-and-type.md](references/composition-and-type.md)
- 完了前検品と版間振り返りの手順： [references/visual-review.md](references/visual-review.md)

## 設計の 5 原則

1. **一画面を一つの構図として組む**: 主役（地図・地形・写真・数値・判定図）の占有を先に決め、付帯情報を主図の側面や隙間に組み込む。全ショット・全章を同じカード枠と中央揃えにしない。
2. **文字を造形と尺度差で組む**: 日本語の主語・数値・欧文識別子・出典ラベルに明確な大小差をつける。CSS や JSON で太字を指定しただけで満足せず、**実際の描画ウェイト**を確認する。
3. **情報密度を 3 層に分ける**: ①一瞬でわかる主語・数値・主図、②見ればわかる凡例・系統名、③詳しく見るための出典・座標・条件を分け、余白や暗面を情報の境界として使う。
4. **色以外でも判別できるようにする**: 強調・警告・階級は塗り面だけでなく、文字・形・太さ・ラベルでも区別する。
5. **時間は局面の切替に使う**: 無意味な常時アニメーションを避け、「静止」と「変化」の対比で場面の切り替わりを伝える。

## 完了前の確認

- 色を抜いた縮小画面で、主図と文字の構図に意図が残っているか。
- 原寸フレームで、使用フォントの実ウェイト（極太・細字の差）と文字の可読性を確認したか。
- 色を取り除いても、数値・形・ラベルから意味を判別できるか。
- 字幕・立ち絵・出典と主図が衝突していないか。
- 観察した事実と設計上の翻案・仮説を混同せず記録しているか。
