# 完了前検品と版間振り返りの手順

レンダリング後に静止画・通常速度動画を確認するときのビジュアル検品プロトコルと、版を重ねる際（例: `v0.1` → `v0.2`）の記録様式。

## 完了前の 4 段階チェック

### 1. 縮小・グレースケール構図チェック
- 代表フレーム（または `--stills` 一覧、`packages/pipeline/video_qa.py --contact` の 4×3 コンタクトシート）を小さく表示し、必要なら彩度を落として見る。
- **確認点**:
  - 主図（地図・写真・数値）の占有意図がひと目でわかるか。
  - どの章も同じ位置・同じ比率のカード配置になっていないか。
  - 文字と図が団子にならず、視線の入口が 1 つに定まっているか。

### 2. 原寸字面・実ウェイトチェック
- 100% 原寸のフレームを開き、タイトル・数値・地名・字幕・出典の文字を確認する。
- **確認点**:
  - 指定した太字（Black/Bold）が代替フォントで細く化けていないか。
  - 3 層のサイズ差（主見出し ＞ 凡例・地名 ＞ 出典・識別子）が保たれているか。
  - 地図の航空写真や明るい地形の上で、文字のコントラストが落ちていないか。

### 3. 色を取り除いた判別性チェック
- 色分け（コロプレス階級、状態色、比較ライン）から色情報を抜いたと仮定しても意味が伝わるか確認する。
- **確認点**:
  - 数値・単位・ラベル語・線の太さや破線・凡例テキストだけで、どれが異常／高値／比較対象か判別できるか。

### 4. 通常速度の動画・干渉チェック
- 静止画だけで完了とせず、音声付き MP4 を通常速度で再生する。
- **確認点**:
  - 字幕（`subtitle`）、立ち絵（`reaction`）、出典、主図や地名ラベルが重なっていないか。
  - 動いている要素が「局面や移動の説明」になっており、意味のない常時揺れ・点滅になっていないか。

## 版間振り返りの記録様式

`v0.1` から `v0.2` へ改訂する際は、感想だけで直さず、次の表で「何が薄まったか／単調だったか」を言語化してからショットを設計し直す。

```markdown
| 旧版の傾向 | 薄まった点・課題 | 次の版で変える点 |
|---|---|---|
| （例）全章を同じ上見出し＋右パネルで組んだ | 場面ごとの主題差が消えた | 章ごとに主図占有型・比較型・数値強調型を切り替える |
| （例）細い明朝体と広い余白でまとめた | 背景地図に文字が負けた | 実ウェイトの太字＋暗面帯で文字の黒みを確保する |
```

## 根拠の区別ルール

設計メモやスキル文書に知見を残すときは、次の 3 つを混同しない。

- **一次事実**: 仕様・実測値・参考動画のフレーム数や実データから直接確認したこと。
- **観察**: 画面や動画を見て読み取った視覚的傾向。
- **翻案**: 本プロジェクトの地理動画やレンダラー向けに再設計・提案したルール。

「資料や原則を読んだだけで見た目が良くなった」と主張せず、必ず書き出した実フレームの比較で判断する。
