# 作品スタイル仕様書（STYLE.md）の設計と運用

複数の章やショット、あるいは複数回のエージェント作業をまたいで映像のルック（色・光・文字・線・カメラ速度）がぶれるのを防ぐため、作品ごとに 1 ファイルのスタイル仕様書（`STYLE.md`）を定めて運用する。

`STYLE.md` は「各ショットの構図まで同じ型に固定する」ためのものではなく、**作品全体で守るべき視覚の不変条件（Visual Contract）**を宣言する設計書である。章ごとの構図シルエットの切り替えは [composition-and-type.md](composition-and-type.md) に従う。

---

## 1. 配置と運用規約

- **配置場所**: 各動画プロジェクトの直下 `projects/YYYY/MM/DD/<slug>/STYLE.md` に置く。
- **作成タイミング**: 企画と章立てが決まり、第 1 章のショット JSON やカスタム図版を書き始める前に初版を固定する。
- **参照の単一ソース**: 章を並列制作するときやカスタム図版（HTML/SVG）を作るときは、色コード・フォントウェイト・空/霧設定・カメラ速度レンジをショットごとに再発明せず、必ず `STYLE.md` から引く。
- **改訂手順**: `v0.1` → `v0.2` でルックを見直すときは、個別ショットだけをつぎはぎせず、先に `STYLE.md` を更新して変更理由を残し、その後で各章のショット JSON へ反映する。
- **実装可能範囲の厳守**: `STYLE.md` には現行レンダラー（`packages/renderer/`）または事前レンダリング図版で実際に制御できる項目だけを書く。未実装のポストプロセスや架空のパラメータを書かない。

---

## 2. `STYLE.md` 標準テンプレート

新規プロジェクト開始時に以下をコピーし、作品に合わせて数値を埋める。

```markdown
# STYLE: <作品の短い主題>

## 1. 視覚コンセプト
- **主題とトーン**: （例：歴史的変遷を落ち着いて辿る／防災・インフラ構造を明快に診断する）
- **時間帯・季節**: （例：澄んだ昼／夕景〜夜間の推移／季節変化）
- **1文ルール**: （例：航空写真の質感を生かし、強調色は 1 色に絞って線と数値で視線を導く）

## 2. カラーパレット（役割固定）
色分けに頼りきらず、線の太さ・破線・ラベル語を併用する。

| 役割 | HEX / 値 | 対応箇所（JSON / CSS） | 使用ルール・制限 |
|---|---|---|---|
| 背景・暗面 | `#0F141B` / `tint: 0.28` | `background`, `tint` | 文字や主図を立たせる暗面帯に使う |
| 主アクセント（1色） | `#E65100` | 主線 `line.color`, 強調数値 | 1 画面の主役 1 系統のみに使う |
| 副次・比較 | `#38BDF8` | 比較線・対照範囲 | 主アクセントと彩度・明度差を保つ |
| 警戒・異常 | `#EF4444` | しきい値超過・異常範囲 | 正常時には使わない |
| 主文字 | `#F8FAFC` | 見出し・数値・字幕 | 明るい地図上では暗面帯または縁取り必須 |
| 副文字・出典 | `#CBD5E1` | 凡例・座標・出典 | 主文字よりサイズ・コントラストを落とす |
| 話者色 | 話者A `#...` / 話者B `#...` | `voices.<id>.color` | 字幕やラベルの識別用 |

## 3. 地図・時間帯・空・霧・3D 質感
| 項目 | 設定値 | 意図 |
|---|---|---|
| ベース地図 (`base`) | （例：`ortho` / `pale` / 年代別空中写真） | 主題に合う背景密度 |
| 色調補正 (`saturation` / `contrast`) | （例：`-0.2` / `0.05`） | 重ねる線と文字が埋もれない背景階調 |
| 標高 (`dem` / `exaggeration` / `hillshade`) | （例：`gsi` / `1.5` / `0.35`） | 地形の起伏が伝わる最小限の強調 |
| 空・霧 (`sky`) | `sky-color`, `horizon-color`, `fog-color`, `fog-ground-blend` 等 | 遠景の抜けと奥行き統一 |
| 3D 建物 (`plateauBuildings`) | `appearance`, `night: [[0, 0]]`, `facadeTextures` 等 | 使用する場合のみ明記（不使用なら「なし」） |

## 4. タイポグラフィと 3 層サイズ階層
実描画フレームで極太・細字の差（実ウェイト）を確認した書体のみ記載する。

- **主書体**: （例：`Noto Sans CJK JP` — Black / Bold / Regular）
- **数値表記**: 等幅数字（`tabular-nums`）必須、単位は数値より 1〜2 段小さく組む
- **サイズ階層（1920×1080 基準）**:
  1. **一瞬でわかる層（主見出し・大数値）**: （例：64〜96px, Black）
  2. **見ればわかる層（地名・凡例・ラベル）**: （例：28〜36px, Bold）
  3. **詳しく見る層（出典・座標・注記）**: （例：18〜22px, Regular）
- **安全域**: `cameraPadding`（例：下端字幕帯 140px）、立ち絵領域と主図・地名を衝突させない。

## 5. 図形・線・オーバーレイの文法
- **線幅レンジ**: 主線 `5〜6px`、副線 `2.5〜3.5px`、補助・境界線 `1.5〜2px`
- **ラベル処理**: 縁取りまたは半透明暗面帯を統一し、角丸・余白を章間で揃える
- **カスタム図版（HTML/SVG）**: 走査線やグリッドの透過率は 4〜6% 以下（H.264 圧縮耐性）

## 6. カメラ速度レンジと時間テンポ
- **許容カメラ範囲**: `pitch`（例：`35°〜60°`）、`zoom`（例：`11.5〜16.0`）、`fov`（例：`36.87` 既定）
- **標準移動**: `path: "fly"`（広域移動） / `path: "linear"`（局所トラッキング）、`ease: "inOut"` を基本とする
- **静止（ホールド）**: 要点の提示後、視聴者が数値・位置を読むために最低 `1.5〜2.5 秒` の静止または極低速区間を置く
- **時間差（Stagger）**: 複数要素の連続出現は `0.1〜0.2 秒` 刻み、全出揃いは `1.0 秒` 以内

## 7. 禁止事項（Invariants）
- 主アクセント以外の高彩度色を 1 画面に乱立させない
- 章ごとに空・霧・背景のトーンを無断で切り替えない（時間帯推移を意図する場合を除く）
- 目的のない常時回転・明滅・浮遊アニメーションを置かない
- 全章を同じ「上見出し＋右カード」の単一構図に画一化しない
- 出典・座標・年代注記（現代地名を重ねる場合の明示を含む）を省かない
```

## 3. 検品時の照合（STYLE.md × visual-review）

[visual-review.md](visual-review.md) の完了前 4 段階チェックを行う際、各章のコンタクトシート（`packages/pipeline/video_qa.py --contact` 等）を横に並べ、次を照合する。

1. **パレットと空・霧の一貫性**: 章の境界で背景の彩度・暗面（`tint`）・空や霧の色が意図せず段差になっていないか。
2. **文字階層と実ウェイト**: `STYLE.md` で定めた 3 層のサイズ差が、実際の 1080p フレーム上で再現されているか。
3. **禁止事項の遵守**: 例外的な演出を入れた場合、それが「局面転換のための意図的な逸脱」か「設定漏れによるブレ」かを区別し、後者なら `STYLE.md` に合わせて修正する。
