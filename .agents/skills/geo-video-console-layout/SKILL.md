# 地理動画のコンソール・計器レイアウト

防災・インフラ・観測・比較を扱う地理動画において、**管制室・診断端末・計器パネル風の視覚文法（FUI）**を取り入れ、局面や数値の変化を明快に見せるための設計スキル。構図・文字造形・検品の基本原則は `geo-video-art-direction` を参照する。

## 最初に決めること

画面を設計する前に、次の 4 点を 1 文で定義する。

> **誰が（観測者・解説対象）／どの端末種別で／どの地理的局面を／何の指標で判断する画面か**

- 装置の立場（広域の共用監視盤・局所の診断端末・時系列の資源/残時間表示・区画警戒マップ）を混ぜない。
- 特定の架空作品のロゴ・商標・固有名詞・意味のない飾り数値は持ち込まない。実在の地名、観測所名、流域、自治体、統計指標をラベルに使う。
- 大きな角丸、半透明カード、全面グロー、無意味な飾りリング、常時点滅を初期値にしない。線の細さ、暗面、尺度差のある文字、状態色の反転で緊張感を作る。

## 完了前の確認

- 実在の地理データ・観測指標に即したラベルと単位になっているか（架空の飾り記号だけで埋めていないか）。
- 「欠測・データなし」を「正常・0」として描画していないか。
- 状態の変化が「色」だけでなく「文字語・面積・線・数値」でも表現されているか。
- `renderer-mapping.md` で実装可能な手段（`choropleth` / `chart` / `counter` / `panel` 等）に落とし込まれているか。
