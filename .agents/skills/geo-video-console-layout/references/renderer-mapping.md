# 現行レンダラーとの対応と実装境界

`packages/renderer/src/types.ts` のショット・オーバーレイ仕様でそのまま実装できる表現（○ / △）と、事前画像・SVG 生成など別の手段が必要な表現（×）を整理する。**実装できない技法をショット JSON に名前だけで書かない。**

## オーバーレイ機能との対応表

| コンソール表現の要素 | 対応 | 現行レンダラーでの実装方法 |
|---|---|---|
| 背景の暗面化・コントラスト確保 | ○ | `tint`（地図の暗転・色味調整） |
| 区画・異常範囲・緩衝帯の面表示 | ○ | `polygon`（単色・境界線）および `choropleth`（2D 階級塗り・3D 押し出し `extrude` / `rise`） |
| 観測網・供給線・経路の伸長描画 | ○ | `line` + `draw`（上流から下流・起点から終点への線描画） |
| 巨大な数値・残時間・カウントアップ | ○ | `counter`（桁・小数点・単位付きの数値計数） |
| 局面・判定語・観測所識別子の配置 | ○ | `label`（地図座標・画面配置の文字札）および `chapter`（章・局面の見出し） |
| 注記・出典・定義の帯表示 | ○ | `note` / `quote` / 自動出典表示 |
| 時系列波形・比較グラフ | ○ | `chart`（折れ線・棒・比較チャートオーバーレイ） |
| 高度な SVG 図解・多系統判定盤・計器 UI | △ | 現行 JSON には専用の多系統ウィジェット型がないため、事前に SVG/PNG として生成し `panel` または `image` として重ねる |
| 7 セグメント風カウントダウンや専用 HUD の動画組込 | ×（JSON 単体） | レンダラーの標準オーバーレイだけでは組めない。専用 HTML/SVG で連番または静止画を生成し `panel` で差し込むか、章間カードとして `chapter_pipeline.py` で結合する |

## 設計時の注意

- ショット JSON を書く前に「標準オーバーレイの組み合わせで組むか」「事前生成した高精細 SVG/PNG 図版を `panel` で出すか」を決める。
- 事前生成した図版を使う場合も、`geo-video-art-direction` の原則（実フォントウェイト確認、色以外での判別性、3 層密度、字幕・立ち絵との非干渉）を適用して検品する。
