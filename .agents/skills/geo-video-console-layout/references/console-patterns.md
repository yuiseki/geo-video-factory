# コンソール・計器レイアウトの 4 パターン

地理・土木・防災解説の主題に合わせて使い分ける 4 つの画面骨格。すべてを同じ「上見出し＋左右均等カラム」にせず、主役の図形・数値に合わせて配置を決める。

## 1. 多系統比較・判定パネル
*向いている題材*: 複数の要因・シナリオ・路線・電源構成・自治体の比較、3 視点からの総合判定。

- **骨格**: 複数の系統ブロック（例: 要因 A / 要因 B / 要因 C）を幾何学的な配置で並べ、中央または下部に**巨大な結論語・判定結果**を置く。
- **密度差**: 各系統の中に「系統名」「判定語（可／不可／超過など）」「根拠となる短い数値」を収め、詳細な注釈は外側の細い帯へ逃がす。
- **地理への応用**: 地図上の対象地域（`polygon` / `choropleth`）の横に、複数要因の比較パネルを配置して「なぜその地域が選ばれた／被災したか」を一画面で示す。

## 2. 診断・時系列波形・位相比較
*向いている題材*: 水位・雨量・地震波形・交通量・気温・潮位・電力需給の時系列推移や 2 地点比較。

- **骨格**: 時間軸を持つ波形・折れ線グラフを画面の主役に据え、片側に**現在値・最大値・基準線超過の有無**を縦に積む。
- **非対称の扱い**: グラフ領域を大きく取り、凡例・観測局名・単位はグラフの余白や端の細い列に組む。
- **欠測の扱い**: データが途切れた区間を線で勝手につないだり 0 に落としたりせず、空白または破線・`NO DATA` ラベルで明確に切り分ける。

## 3. 残時間・資源・カウントダウン
*向いている題材*: 津波到達予想時間、工事工期、人口減少・備蓄・予算・供給余力の推移、歴史年表の進行。

- **骨格**: 巨大な等幅数字（または桁区切りの明確な数値）を主役に据え、そのすぐ近くに「何の残り時間／資源か」を示す短い日本語見出しと進捗バーを置く。
- **切替の演出**: しきい値を下回った瞬間や目標年に達した瞬間に、数値の強調色と状態語（「通常」→「警戒」→「超過」）を切り替える。

## 4. 警戒・防壁・区画マップ
*向いている題材*: 氾濫想定区域、土砂災害警戒区域、津波浸水範囲、停電・断水・交通遮断エリア、都市開発区画。

- **骨格**: 地図（地形・航空写真・区画ポリゴン）を全面に広げ、**影響範囲・遮断線・保護対象**を塗り面と太い境界線で対比させる。
- **連続性の表現**: 独立したアイコンを並べるのではなく、河川・道路・送電網・区画の「連結と遮断」「拡大と縮小」が地図上で連続して読めるようにする。
- **付帯情報**: 影響戸数・延長距離・対象自治体名は地図の暗い帯（`tint` や端の列）にまとめる。
