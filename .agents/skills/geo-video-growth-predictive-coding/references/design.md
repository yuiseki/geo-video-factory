# 設計: 予測、誤差、解消を時間軸に置く

## 点検の問い

| 問い | 足りないときの症状 | 手当て |
|---|---|---|
| 視聴者は、この画の次を予測できるか | 何を見ればよいか分からない | 誰もが知る目印や常識の画を先に置く |
| その予測は強く、視聴者のあいだで共有されているか | 「地味」「どこにでもある」 | 無名の場所だけで始めない。有名な場所と対比させる |
| 予測を裏切る誤差が 1 つ、はっきり立っているか | 「何がすごいのか分からない」 | 「〜なのに無い」を数字と画で言い切る |
| 誤差は信頼されているか (精度) | 「CG でしょ」「盛ってる」 | 出典、実測と推定の区別、数字を画面に出す |
| 誤差は映像の中で解消されるか | もやもやして終わる、釣りと思われる | 種明かしの画を、誤差のすぐ後に置く |
| 解消の局面が見どころになっているか | 山が無い | 解消を段階に分ける (形が立つ、色が付く) |
| 次の誤差がすぐ立つか | 途中で離脱される | 解消したら、次の問いを短い間隔で置く |

## 例: PLATEAU の無い街を 3D にする 60 秒

| 秒 | 役割 | 画 |
|---|---|---|
| 0〜5 | 予測を呼び出す | 都心の高層ビル群を、写真付きの 3D で (「東京の 3D 地図」という共有の予測) |
| 5〜11 | 誤差を立てる | 西へ約 40 km 飛び、3D の建物が 0 棟の街に降りる (「東京なのに無い」) |
| 11〜20 | 解消 1 | 地面から白い模型が立ち上がり、棟数が回る (形と高さ) |
| 20〜28 | 解消 2 | 2 つ目の波で色が付く。屋根は空中写真そのもの |
| 28〜40 | 精度 | 市境の比較 (従来と本手法)、実測と推定の断り書き |
| 40〜60 | 次の問いと締め | 地元の目印で現在地を示し、総数で締める |

最初の版は、無名の住宅街だけで始めた。視聴者に予測が無いので裏切りようがなく、「地味」と言われた。夜景も足したが、情報が増えない演出で、予測誤差を立てなかった。

## 文字の書き方

- 予測と誤差は、数字と固有名詞で書く (「羽村市 3D の建物 0 棟」)。
- 雰囲気のコピー (「街がつながる」「すべてを立体に」) は、予測を呼び出さず、誇張として精度を下げる。
