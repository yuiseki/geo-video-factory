# 予測と予測誤差で構成を設計する

視聴者は映像を受け身で見ていない。頭の中のモデルで次の画を予測し、予測と違った所 (予測誤差) にだけ注意を向け、信念を書き換える。動画の構成は、この予測と誤差と解消の流れとして設計できる。

刺激の量や「報酬」で注意を引く設計 (`geo-video-growth-dopa`) とは別の枠組みで、混ぜない。こちらは、視聴者のモデルに何を書き込むかを問う。

## 手順

1. 視聴者がすでに持っている、強く共有された予測を探す。目印、常識、よく知る景色。[references/theory.md](references/theory.md)
2. その予測を呼び出す画を先に置く。予測が弱い題材 (知られていない場所、無名の街) は、それだけでは裏切りようがない。
3. 予測を裏切る、信頼できる誤差を 1 つ立てる。「〜なのに、ここには無い」「〜のはずが、違う」。
4. 誤差を映像の中で説明し、減らしていく。解消の局面が見どころの山になる。
5. 誤差を信頼させる精度を足す。実データの出典、推定と実測の区別、数字。誇張は誤差を雑音に変える。
6. 誤差を立てては解消する山を、短い間隔で置き直す。学ぶことが尽きた所で視聴者は離れる。[references/design.md](references/design.md)

## 守ること

- 理論の言葉を、視聴者の脳の測定や診断として語らない。設計の物差しとして使う。
- 解消しない誤差 (釣り、回収しない予告) を置かない。解消の見通しの無い誤差は、不安や離脱になる。
- 雰囲気だけのコピーで予測を作らない。予測は画と数字と固有名詞で呼び出す。
