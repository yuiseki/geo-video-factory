# 長尺動画の導入設計（冒頭 30 秒）

長尺動画における冒頭 30 秒は「入口の設計」であり、本編とは異なる編集方針を採る合理性がある。YouTube の視聴維持分析では開始 30 秒が `Intro` 区間として扱われ、自動再生プレビューでは最初の 10〜30 秒がサムネイルの延長として機能する。

## 3つの導入構造

| 構造 | 流れ | 特徴と注意点 |
|---|---|---|
| **A. 従来型** | 挨拶 → 自己紹介 → 背景 → 目次 → 本題 | 説明的。視聴意欲がすでにある視聴者には向くが、初見視聴者は価値が伝わる前に離脱しやすい |
| **B. ドパ導入（推奨）** | **結果 → 驚き → 問い → 期待 → 本編** | 挨拶や不要な OP アニメを省き、最初に強い印象や結論の一部を提示し、本編でその意味を解き明かす |
| **C. 全編高刺激** | 刺激 → 刺激 → 刺激 → 刺激 → 刺激 | 変化や休止が少なく情報処理負荷が高い。本編の理解を妨げ、後半で視聴者が疲弊する |

## 地理・地図解説の冒頭 30 秒モデル

「結論を最後まで隠す」のではなく、最初に価値のある結果や動きを一部見せてから、本編で原理や経緯を説明する。

| 時間 | 役割 | 地理動画での具体例 |
|---|---|---|
| **0〜3 秒** | 最も印象的な結果 | 説明抜きで完成形の 3D 地形・コロプレス上昇・劇的な比較地図を見せる |
| **3〜8 秒** | 意外性の提示 | それが普通の地図・通説とどう違うのかを一言で示す |
| **8〜15 秒** | 問いの設定 | 「なぜこうなるのか」「どこに謎や難しさがあるのか」を提示する |
| **15〜25 秒** | 視聴価値の約束 | 本編で扱うデータ、検証、たどるルートや時代を示す |
| **25〜30 秒** | 本編への移行 | テンポを落とし、落ち着いた解説・掛け合いへ自然に移る |

## 高刺激な導入を採用しない方がよい場面

- **静かな紀行映像・長回し重視の記録映像**: 派手なカット割りや効果音が作品本来の価値と対立する。
- **リラックス目的のコンテンツ**: 落ち着いたリズム自体が視聴者の期待である。
- **講義・公共的説明動画**: 過剰演出は説明の正確性や信頼性を損なうおそれがある。
- **本編で回収できない予告**: 後半で実現しない成果を冒頭で煽ると、短期的な維持と引き換えに長期的な信頼を失う。
