# 安全性・アクセシビリティと効果検証

## 1. 認知的・倫理的配慮と限界

- **ミームと科学の区別**: 「ドーパミン中毒」「ドパ」は文化的・編集的なメタファーであり、実際のドーパミン分泌量や医学的依存症（WHO ICD-11 のゲーム障害等）の診断とは異なる。台本や解説で科学的事実のように混同しない。
- **視聴時間と満足度の区別**: 再生維持だけを目的に結論を不自然に引き延ばすと、短期的な再生時間と引き換えに視聴者の信頼と長期満足を損なう。視聴後に「時間を使ってよかった」と感じられる情報価値を優先する。
- **過度な刺激による疲労**: 短尺動画の過度な利用と注意の断片化などの関連を指摘するレビューもあるため（BMJ Public Health, 2026）、情報の理解を阻害する無意味な高刺激の連打は避ける。

## 2. アクセシビリティ基準（WCAG 2.2 準拠）

光過敏性や感覚過敏を持つ視聴者を守るため、以下を制作ルールとして守る。

- **閃光制限**: W3C WCAG 2.2 に基づき、**1秒間に3回を超える閃光（フラッシュ・急激な明滅）を生じさせない**。
- **画面振動と音量**: 過度なカメラシェイクや、前触れのない極端な音量ジャンプを避ける。
- **可読性の維持**: テンポが速いカットでも、字幕・地図ラベル・凡例が読める表示時間とコントラストを確保する。

## 3. 効果検証の実験設計（仮説を数字で確かめる）

感覚だけで「ドパ系編集が効いた」と判断せず、最小の比較実験で要因を切り分ける。

### 2×2 の最小比較計画

同一テーマの解説（例：30秒動画）で「結論の位置」と「刺激密度」の2軸を分ける：

| | 低刺激編集 | 高刺激編集 |
|---|---|---|
| **結論を冒頭に配置** | A：即時価値提示型 | B：即時価値＋高刺激型 |
| **結論を後半に配置** | C：期待蓄積型 | D：期待蓄積＋高刺激型 |

### 測定すべき指標

- **冒頭離脱率**: 最初の数秒で注意を獲得できたか
- **30 秒時点の維持率**: 長尺動画の `Intro` が機能したか
- **継続視聴（Engaged views）**: 単なる再生開始・リプレイではなく実際に視聴が続いたか
- **平均視聴時間 / 完視聴率 / 再視聴率**
- **保存・共有率**: 後で参照したい・人に伝えたい価値があったか
- **理解度テスト・視聴者満足度**: 内容が正しく伝わり、時間を使う価値があったか

### 検証すべき主な仮説

- **H1（冒頭の価値提示）**: 派手な編集よりも、最初に具体的な結果を見せる方が初期離脱を減らす。
- **H2（編集密度）**: 適度なカット頻度は維持率を改善するが、過剰な視覚情報は理解度を低下させる。
- **H3（報酬の一致）**: 冒頭演出と本編で提供する価値が一致している場合に視聴者満足度が高まる。
- **H4（ショートから長尺への移行）**: ショート動画が単独でも完結している場合、強引に結末を隠す方式より質の高い長尺視聴につながる。
