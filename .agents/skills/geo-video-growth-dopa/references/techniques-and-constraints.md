# 演出の4機能・技法とレンダラーへの落とし込み

## 1. 映像演出の4つの役割

すべての刺激・演出を「派手にするため」ではなく、以下の4機能のいずれかとして配置する。

| 役割 | 目的 | 代表的な表現 |
|---|---|---|
| **注意の獲得** | 動画を見る理由を与える | 強い冒頭映像、意外な事実・比較、通説への違和感 |
| **期待の形成** | 続きを見たい状態を作る | 問い・謎、予告、未完了のルートやゲージ |
| **報酬の提供** | 視聴を続ける価値を実感させる | 答え、発見、納得、美しい俯瞰、数値の確定 |
| **注意の再獲得** | 単調さによる離脱を防ぐ | 場面転換、視点変更、強調対象の切り替え |

※ 報酬とは大音量や閃光だけではなく、**「複雑な問題が解ける瞬間」「地図の見方が変わる瞬間」**といった知的発見を含む。

## 2. 代表的な編集技法と `geo-video-factory` での実装対応

| 技法 | 導入・ショートでの用途 | `geo-video-factory` での表現手段 |
|---|---|---|
| **コールドオープン** | 挨拶を省き、出来事の途中や結果から始める | 冒頭ショットにタイトルカードや挨拶を置かず、いきなり `rise` や飛行映像から開始する |
| **ハイライト先出し** | 後半の見せ場を冒頭数秒に短く置く | 本編後半の 3D 都市・ピーク場面のショットを冒頭 0〜3 秒に先行配置する |
| **ティーザー** | これから起きる変化を予告する | 広域図に短い `label` / `note` とこれから辿る `line` の始点を示す |
| **ジャンプカット** | 不要な無音や移動の待ち時間を削る | ショットの `duration` を詰め、不要な静止ホールドを省く |
| **モンタージュ** | 複数場面を短時間で重ねて全体像を予感させる | 1〜1.5 秒の短いショットを連続させ、各地点や時代変化をテンポよく繋ぐ |
| **インサートカット** | 発言に対応する資料・写真を挟む | `image` / `photo-marker` で現地写真や過去地図をピンポイントに挿入する |
| **サウンドヒット** | 重要な瞬間に効果音を合わせる | ナレーション台本・音声合成の節目（数値到達・切り替え）に SE を配置する |
| **スピードランプ** | 移動・変化の速度に緩急を付ける | `ease: "inOut"` や複数キーフレーム (`keys`) で、視線移動を速く・注視点をゆっくりにする |
| **パターンインタラプト** | 構図・音声・色の変化で注意を再獲得する | `focus` による対象以外の減光 (`dimOpacity`)、2D/3D 切り替え、話者交代 |
| **クリフハンガー** | 未解決の問いを残して次章へつなぐ | ショットの最後に「なぜこの場所だけ高いのか？」の問いを置き、次ショットでズームインする |

## 3. 「ドパ系」UI・学習アプリから持ち帰れる設計ヒント

2025〜2026年の「ドパガキ / ドパ系」ミームおよび派生学習アプリ（計算・地理・漢字・英単語系）に共通する表現上の特徴と、地理動画への適切な取り入れ方：

- **即時フィードバック**: カメラが目標へ到達した瞬間や数値が増えた瞬間に、ラグなくラベル・色・音を反応させる（例：`rise` と同時にラベルの大きさと濃さが連動して立ち上がる）。
- **希少性・極端値の可視化**: ランキングや偏差において、突出した上位対象だけを `focus` で残し、他を半透明にして一目で差を伝える。
- **演出のインフレーションとダイナミックレンジ**: 段階的に情報を盛り上げることは有効だが、**すべての音を大きく・すべての場面を派手にするとダイナミックレンジが失われる**。強調したい直前・直後に必ず落ち着いた静かな区間を置く。
