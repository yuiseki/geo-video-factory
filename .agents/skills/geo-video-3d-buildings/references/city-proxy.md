# PLATEAU の無い街を建てる (city proxy)

PLATEAU は整備された市区町村にしか無い。OSM の建物も郊外では穴が多い (羽村・福生の範囲で地理院 27,467 棟に対し OSM 4,808 棟)。地理院の最適化ベクトルタイル (`optimal_bvmap-v1`、レイヤー `BldA`) には 1/2,500 基盤地図の建物の外形が全国そろっているので、これを建物の形の正本にする。

## 流れ (packages/pipeline)

| 段 | モジュール | 中身 |
|---|---|---|
| 形 | `gsi_footprints.fetch_gsi_buildings` | z16 の `BldA` を読み、タイルの境で切れた建物をつなぎ直す。`vt_code` は 3101 普通、3102 堅ろう、3103 高層、3111/3112 無壁舎 |
| 地面 | `gsi_footprints.dem_sampler` | レンダラーが地形に使う `dem_png` z14 と同じ標高。建物の足元をここに置き、0.4 m 沈める |
| 除外 | `glb_spatial.extract_glb_feature_heights` | PLATEAU の建物の重心を含む外形は作らない (PLATEAU を優先) |
| 高さ | `building_heights` | OSM の `height`、次に `building:levels` x 3 m、無ければ分類と床面積の区分ごとの中央値。中央値は近くの PLATEAU で較正する (福生 7,589 棟)。推定元を建物ごとに残す |
| 形を作る | `city_proxy` + `city_geometry` | 全部を 1 つの GLB、1 つの材質にする (2 万棟で 1 回の描画)。小さな長方形の普通建物は寄棟か切妻 (建物 ID で決まる)。屋根の色は外形の中の空中写真の中央値、壁は分類ごとの推定色 |
| 影 | `city_geometry._shadow_glb` | 太陽と逆向きに外形を伸ばし、全部を合わせて重なりを消し、40 m の升目で切って地面に沿わせる |

公理: すべての建物は 1 階以上の高さを持つ (`ONE_STORY_M`)。1 階は推定の下限で、既定値ではない。

## 描画 (packages/renderer)

- タイルは `frame: "enu"` (中心からの東・上・南のメートル、標高は絶対値)。`kind` は `city-proxy` と `city-shadow`。
- `city-materials.ts`: 頂点色、`uv` = (壁に沿ったメートル, 足元からの高さ)、`_style` = (0 住宅 / 1 堅ろう / 2 無壁, 軒の高さ)。窓は階ごとの行と柱間ごとの列にそろえた四角形で、有無は列ごとに決める。1 階が数ピクセルより小さくなる距離では、四角形をやめて窓の平均の色にする (遠くの壁が黒い粒にならない)。
- `plateauBuildings.reveal`: 建物が地面から立ち上がる波。`radius` は [秒, メートル] の時刻表で、縮めると外側から沈む (巻き戻し)。
- `plateauBuildings.night`: [秒, 0..1] (0 昼、0.5 夕方、1 夜)。光の色と強さ、空中写真の明るさ、影の濃さ、窓の明かりが一緒に変わる。
- 影は太陽 (-300, -450, 450) に合わせて焼いてある。どちらかを変えたら `SHADOW_PER_M` も変える。

## 落とし穴

- 地形の高さ強調 (既定 1.3 倍) は建物を埋める。建物を出すスペックでは既定で 1 倍にした。明示して上書きしない。
- DracoPy が無いと、Draco 圧縮の PLATEAU から重心も高さも読めない。以前は黙って空になり、OSM の建物が PLATEAU と二重に建った。今は止まる。
- 建物ごとに別の材質やメッシュにすると、建物の数だけシェーダーができ、読み込みに 20 分かかった。1 タイル 1 材質にする。
- 太陽が高いと (仰角 60 度台) 影は 2 階建てで 3 m ほどしかなく、上空からは見えない。

## 画面に出す断り書き

屋根の色は空中写真から、高さは較正した推定、屋根の形と窓と壁の色は推定。この 3 つを画面で分けて書く。推定の窓や屋根を実在のものとして説明しない。
