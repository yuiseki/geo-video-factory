# 報告の型

分析は保管庫の中 (`<保管庫>/ANALYSIS.md` か、動画ごとのフォルダ) に書く。リポジトリには入れない。リポジトリやスキルに戻すのは、名前を外して型にした知見だけ ([findings.md](findings.md)、各スキルの references)。

## 1 本ごと

```markdown
## <題> (<チャンネル>)

利用者の一言: 「...」

### 数字
| | |
|---|---|
| 登録者、再生、登録者あたり | |
| 高評価率、コメント数 | |
| 公開日、取得日 (公開から N 日) | |
| 長さ、章 (平均) | |
| 画面の切り替わり | |
| 動いている時間、寄りの速さ | |
| 見た目の変化、同じ見た目の最長 | |
| 話す速さ (全体) | |
| 声、BGM、音量 | |
| 素材と道具 (概要欄から) | |

### 骨組み
### 冒頭
### 画の文法
### 誠実さ
### 終わり方
### 題とサムネイル
### 気になる所
```

各節は [viewpoints.md](viewpoints.md) の観点で書く。時刻 (「4:50 から」) を添え、利用者があとで確かめられるようにする。

## 複数本のまとめ

- 共通すること: 何本中何本に当てはまるかを書く。
- 同じチャンネルの中で差が出たこと: 数字の差と、入り口、骨組み、終わり方の違いを並べる。
- 傾向が [findings.md](findings.md) と食い違ったら、findings.md を直す提案をする。

## 持ち帰りの候補

自分たちの動画とテンプレートに対して、取り入れられる型を番号つきで並べる。

| 列 | 中身 |
|---|---|
| 型 | 何をするか (動画名を出さずに) |
| なぜ効きそうか | 分析の裏づけ |
| 自分たちの動画での使いどころ | 具体的な章や場面 |
| テンプレートでできるか | ○ できる、△ 近いことができる、× できない (`geo-video-visuals/references/README.md` の対応表と合わせる) |

どれを取り入れるかは利用者が決める。× の型を作る場合は、テンプレートへの追加として別に提案する。
