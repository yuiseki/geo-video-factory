# ショットレシピカード集（MapLibre / PLATEAU / 発話・ビート連動）

各シーンのカメラを毎回ゼロから手探りせず、再現可能な「ショットレシピ」から選んでパラメータを調整する。レシピは `geo-video-factory` のレンダラーが実装している機能（`center`・`zoom`・`pitch`・`bearing` の `from`/`to`/`keys` 補間、`ease`、`path: "fly"` / `curve`、`ShotSpec.fov`、`cameraPadding`、オーバーレイの `show`/`draw`/`rise`/`fade`、`plateauBuildings.night`、VOICEVOX 発話レイアウト）だけで成立する構成に限定する。

---

## 1. イージング・緩急・画角の設計規約

### 1.1 `ease` と `path` の選び方

レンダラーはショット全体の進行度 `t`（`0..1`）に `ease` を適用してから、`keys` の区間ごとに線形補間（`path: "fly"` のときのみ van Wijk & Nuij のズーム・パン結合補間）を行う。

| 用途・トーン | `ease` | `path` | 特性と使いどころ |
|---|---|---|---|
| 解説・定着・資料読解 | `smooth` (`3t²-2t³`) | `linear` | ピーク速度が 1.5 倍に抑えられ、地図や地名を読みながら移動できる。標準の第一候補 |
| 導入・着地・主題提示 | `out` (`1-(1-t)³`) | `linear` | カット頭で素早く動き、後半で減速して着地する。着地後の減速域でラベルと発話を読ませる |
| 送り出し・次カットへの吸い込み | `in` (`t³`) | `linear` | ゆっくり動き出して終端で加速する。単体で止めず、次ショットの初動や章転換へ繋ぐ |
| 標準の加減速 | `inOut`（既定） | `linear` | 中央のピーク速度が 3.0 倍と大きい。短距離移動のみに留め、長距離や高ズームでは避ける |
| 複数 `keys` の等速追従・多段制御 | `linear` | `linear` | `keys` 側の `t` 間隔で速度を直接設計したいとき。`ease` との二重加減速を防ぐ |
| 長距離・大縮尺差の空間移動 | `smooth` または `inOut` | `fly`（`curve: 1.2〜1.6`） | 広域へ引いて水平移動し目的地へ降下する結合軌道。画面上の見かけのパン速度を均一化する |

### 1.2 焦点アンカーと 2.5D/3D の運動制約

- **1 ショット 1 主軸を基本にする**：`center` 移動・`zoom` 変化・`pitch` 起こし・`bearing` 旋回を同時に大きく動かすと酔いと視線迷子が起きる。動かす軸は 1 つ（最大 2 つ）に絞る。
- **焦点アンカーの固定**：3D 建物（PLATEAU）やランドマーク周辺で立体感を見せるときは、注視対象を `center` に固定したまま `bearing` だけを回すか、向きを固定して `center` だけを進める。
- **画角（`fov`）はチャプター単位で固定する**：`ShotSpec.fov`（既定約 `36.87` 度）は初期化時に一度だけ設定され、フレーム補間できない。都市 3D の迫力・奥行きを重視するチャプターでは広角側（`42〜50`）、遠景の山並み圧縮や地図の歪み低減を重視するチャプターでは標準〜望遠側（`28〜36`）を選ぶ。単一ショット内のドリーズームは不可。
- **余白（`cameraPadding`）を構図に含める**：字幕帯や立ち絵と主題が重ならないよう、`1920×1080` 基準で `bottom` 等の余白を確保してから `center` と `zoom` を決める。

### 1.3 カット間接続（運動ベクトルと緩急の連続性）

- **同姿勢接続**：発話の区切りや時代切替（`base` / `image` のクロスフェード）でショットを分けるときは、前ショットの `to`（または末尾 `keys`）と次ショットの `from` を完全一致させる。
- **同方向カット**：連続する移動カットでは進行方向やズーム方向（寄り→寄り、川下り→川下り）を揃える。反対向きの移動をハードカットで繋ぐと方向感覚が崩れる。
- **動→静→動の緩急**：移動ショット（`ease: "out"` で着地）の直後に静止ホールドまたは極微速ドリフトを挟む。全ショットが同じ速度で動き続けると単調なスライドショーに見え、視覚疲労も増える。

## 2. 発話リズム・BGM ビート・効果音との同期ルール

### 2.1 発話リズム優先（台詞ありショット）

台詞（`lines`）があるショットは、レンダラーの音声レイアウト（既定 `padStart: 0.3` 秒、`pause: 0.25` 秒、`padEnd: 0.4` 秒）によって実測音声尺が `duration` を上回ると自動で引き伸ばされる。

- カメラの到達点やオーバーレイの `show` / `draw` / `rise` は、**仮の文字数推定ではなく音声実尺の割合 `t`（`0..1`）** で合わせる。
- キーワードを言い切る時刻の少し手前（約 0.2〜0.3 秒前）までにカメラの主要移動を終えるか減速域へ入れておき、発話の理解と画面の着地を揃える。
- 長距離移動を短い一言（2〜3 秒）に押し込まない。移動・広域確認・主題着地を別ショットへ分ける。

### 2.2 BGM ビート同期（無音・導入・章転換ショット）

発話のない導入モンタージュ、章扉、ダイジェスト、無音遷移では、使用する BGM の BPM から拍グリッドを計算して `duration` を決める。

- 1 拍の長さ：`beatSec = 60 / BPM`（例：120 BPM なら `0.5` 秒、100 BPM なら `0.6` 秒）
- 1 小節（4/4 拍子）：`barSec = 4 × beatSec`（例：120 BPM なら `2.0` 秒）
- 無音カットの `duration` は **2 拍・4 拍・8 拍など拍の整数倍** に揃える（フレーム丸め誤差は 30fps で ±1〜2 フレーム以内）。
- 発話ありショットでも、章の切り替えや導入の最初の一音に合わせて `padStart` / `padEnd` を微調整すると全体のテンポが締まる。

### 2.3 効果音・トランジションとの連動設計

`ShotSpec` 自体には個別効果音（SFX）トラックやワイプ描画機能はないため、後段の FFmpeg 音声ミックス（`geo-video-bgm` 等）で効果音を合わせる前提で、ショット設計メモに以下の**基準時刻（秒）**を残す。

- **ウーシュ / スライド音**：`path: "fly"` の上昇開始、`ease: "out"` カット頭の初動、`keys` の方向転換点。
- **ヒット / 着地音**：プッシュイン着地フレーム、`counter` のカウント完了、`chapter` タイトル出現点（`show[0]`）。
- **切替音（シャッター / クロスフェード）**：過去空中写真や衛星画像 `base` / `image` の `show[0]`、`photo_marker` 出現点。

## 3. ショットレシピカード一覧

### R1. エスタブリッシング・ホールド（舞台提示＋微速ドリフト）
- **目的**：舞台となる地域・地形・主要ランドマークの位置関係を一目で理解させる。
- **向いている題材**：章の導入、街区と川・駅・湾岸の全体像、歴史解説の現在地確認。
- **緩急タイプ**：静〜穏（エネルギー低）
- **MapLibre 構造**：
  - `from` → `to` で完全静止、または `zoom` を `+0.15〜+0.3` だけ変化（あるいは `bearing` を `±5〜8°` だけ微速旋回）。
  - `pitch: 0`（真俯瞰で配置重視）または `35〜50`（地形・街並みの立体感重視）。
  - `ease: "smooth"`（または `linear`）。
  - 連動：`chapter` タイトル、主要ランドマーク `label`（最大 3〜5 個）。
- **推奨尺・同期**：4〜7 秒。発話 1〜2 文、または無音なら BGM 2〜4 小節。
- **破綻パターンと回避策**：
  - 静止時間が長すぎると画面が止まって見える → `zoom` を `+0.2` だけ動かすか、後半に `label` を段階表示する。
  - 字幕帯に主要ランドマークが隠れる → `cameraPadding.bottom` を確保して中心を上に逃がす。

### R2. プッシュイン・ランディング（主題への着地）
- **目的**：広域から特定の施設・交差点・地形へ視線を絞り込み、着地と同時に説明を読ませる。
- **向いている題材**：問題提起の焦点化、事件・土木構造物・駅前のクローズアップ導入。
- **緩急タイプ**：中→静（初速あり、終盤定着）
- **MapLibre 構造**：
  - `from`: 周辺ランドマークが入る `zoom`（例 `z13.5`） → `to`: 主題中心 `zoom`（例 `z16.0`）、`pitch` は `30 → 55` 程度まで穏やかに起こす。
  - `ease: "out"`（前半 60% でほぼ移動を終え、後半 40% でゆっくり着地）。
  - 連動：`label` や `photo_marker` は `show: [0.45, 1.0]` のように減速域に入ってから出す。
- **推奨尺・同期**：3.5〜6 秒。発話のキーワード言い切りが `t ≈ 0.5〜0.7` に来るよう配分する。
- **破綻パターンと回避策**：
  - `ease: "inOut"` で大きくズームすると中盤が速すぎて酔う → `out` か `smooth` を使う。ズーム差が `3` 以上かつ横移動が大きい場合は R5（`path: "fly"`）に切り替える。
  - 寄りすぎて周辺との位置関係が切れる → 画面端に川・線路・幹線道路のいずれか 1 本を残す。

### R3. アンカー・オービット（焦点固定 3D 旋回）
- **目的**：PLATEAU 3D 建物やランドマークを立体的に見せつつ、周囲の街区や地形との繋がりを伝える。
- **向いている題材**：都市再開発、高層ビル群、駅周辺、城郭・橋梁、3D 地形の独立峰。
- **緩急タイプ**：穏〜中（一定の立体回転）
- **MapLibre 構造**：
  - `center` を対象に固定し、`zoom`・`pitch`（`55〜68`）をほぼ固定、`bearing` を `30°〜90°` 回転（一周させる場合は `keys` を 90° 未満刻みで 4 区間以上置く）。
  - `ease: "smooth"`（部分旋回）または `ease: "linear"`（360° 連続旋回）。
  - 連動：必要なら `plateauBuildings.night` で昼→夕→夜の時間帯遷移を重ねる。
- **推奨尺・同期**：5〜10 秒（回転角速度の目安は `8〜15°/秒`）。長めの解説発話 1〜2 ターンに合わせる。
- **破綻パターンと回避策**：
  - 回転中に 3D 建物の実カバレッジ端が画面に入り、突然更地になる → 全方位の被覆を事前に確認し、欠ける方位は回さない。
  - 旋回中に DOM ラベル同士が交差する → ラベル数を 2〜3 個に絞り、`--check-label-overlap` で全フレーム検査する。

### R4. リバー／ストリート・トラッキング（経路同期追従）
- **目的**：川・鉄道・運河・街道などの線状構造に沿って移動しながら、両岸や沿線の変化を説明する。
- **向いている題材**：河川治水、鉄道延伸、街道・運河の歴史、物流ルート。
- **緩急タイプ**：中（等速進行）
- **MapLibre 構造**：
  - 経路に沿った 3〜6 点の `keys` を用意し、各区間の地理距離と `t` の幅を比例させる。
  - `bearing` は進行方向（または斜め前方 20°〜35° のサイドトラッキング）に保ち、急旋回を避ける。
  - `ease: "linear"`（区間速度のムラを防ぐ）。
  - 連動：`line` オーバーレイの `draw: [0.05, 0.92]` をカメラの `keys` と同じ時間軸に揃える。
- **推奨尺・同期**：6〜12 秒。沿線の通過地点ごとに発話と `label.show` を順次点灯させる。
- **破綻パターンと回避策**：
  - `keys` の距離が不均等なまま `t` を等間隔にすると途中で急加速・急減速する → 距離比に合わせて `t` を割り振る。
  - 実在しない直線や概略経路を実ルートのように見せてしまう → 概略である旨を `note` または字幕で明示する。

### R5. フライアーク長距離遷移（van Wijk & Nuij 結合移動）
- **目的**：離れた都市・地域・大陸間を、方向感覚とスケール感を保ったまま滑らかに繋ぐ。
- **向いている題材**：産地と消費地、海外と日本、広域インフラ網、歴史的な移動経路の導入。
- **緩急タイプ**：静 → 動（放物線） → 静
- **MapLibre 構造**：
  - 単一ショットに詰め込まず、**① 出発地ホールド（2 秒） → ② 結合移動ショット（`path: "fly"`, `curve: 1.42`, `ease: "smooth"`） → ③ 到着地ホールド（2 秒）** の 3 ショット構成（または広域確認を挟む 4 ショット構成）にし、隣接ショットの `to` と `from` を一致させる。
  - 日本国外の近景を含む場合は `worldFade` を日本近景側（例 `[8, 9.5]`）に寄せる。
- **推奨尺・同期**：移動ショット単体で 4〜7 秒。移動中は短い繋ぎ発話か無音（BGM 2〜4 小節）にし、位置関係の解説は前後のホールドで行う。
- **破綻パターンと回避策**：
  - `path: "linear"` のまま大移動＋大ズームすると起点が即座に画面外へ飛び、終盤で猛スピード横滑りする → 必ず `path: "fly"` を使う。
  - 経由地のない洋上や中間点で不自然に止まる → 広域ショットでは出発地と目的地の両端ラベルを同時に出し、構図の意味を明示する。

### R6. 時代クロスフェード・ロック（同画角・時系列切替）
- **目的**：地形・街区の変化を「同じ画角のまま」比較し、変化量そのものを主役にする。
- **向いている題材**：埋め立て・区画整理・駅前再開発・災害前後の空中写真比較、衛星画像の季節変化、PLATEAU の昼夜比較。
- **緩急タイプ**：静（カメラ固定、レイヤーのみ変化）
- **MapLibre 構造**：
  - `from` と `to` を完全同一（または `zoom` 変化 `±0.1` 以内の極微速）にロックする。
  - `base`（年代別地理院空中写真）または `image`（衛星テクスチャ等）の `show: [t0, 1.0]` と `fade: 0.12〜0.18` で滑らかに重ねる。昼夜比較なら `plateauBuildings.night` を使う。
  - 連動：年代を示す `note` / `counter` を切替点 `t0` に同期させる。
- **推奨尺・同期**：4〜8 秒。発話で「これが現在では…」と切り替わる瞬間に `show[0]` を合わせる。無音比較なら BGM の小節頭（拍の頭）で切り替える。
- **破綻パターンと回避策**：
  - 時代切替と同時にカメラを大きく動かすと、どこが変わったのか視聴者が追えない → 比較の瞬間はカメラを止める。
  - 過去の空中写真に現代の地名ラベルを無断で載せて誤解を招く → 現代の参考地名であることを画面上で明示する。

### R7. プルアウェイ・スケール開示（局所→広域の種明かし）
- **目的**：近景の疑問・ディテールからカメラを引き、背後にある広大な地形・都市構造を明かす。
- **向いている題材**：一見普通の街角が実は巨大な窪地・埋立地・断層線上にある、といった「種明かし」展開。
- **緩急タイプ**：静→動（後半に向けて視野拡大）
- **MapLibre 構造**：
  - `from`: 主題の近景（例 `z16.0, pitch: 55`） → `to`: 広域構造が収まる構図（例 `z12.5, pitch: 25〜35`）。
  - 中心の移動が小さければ `ease: "smooth"`、中心も大きくずらす場合は `path: "fly"` を使う。
  - 連動：広域構造を示す `polygon` や `line` は引き切った後半（`show: [0.55, 1.0]`）にフェードインする。
- **推奨尺・同期**：4〜7 秒。発話の「実はその周囲を見ると…」の直前から引き始め、結論の言葉で全体像が収まるようにする。
- **破綻パターンと回避策**：
  - 3D 建物表示中にデータ範囲外まで引き、建物の途切れが露出する → 3D 建物の実カバレッジ内で止めるか、広域は別ショット（2D オルソ＋地形）へカットで切り替える。

### R8. 地形リビール・チルトアップ（遮蔽越し出現）
- **目的**：手前の尾根・段丘・街区から視線を起こし、奥に広がる山並み・盆地・湾岸を段階的に現す。
- **向いている題材**：火山・カルデラ、河岸段丘、港湾と背後の山脈、盆地の地形的閉鎖性。
- **緩急タイプ**：穏→壮大（視界の解放）
- **MapLibre 構造**：
  - `dem`（`gsi` または `mapterhorn`）と `exaggeration` を有効にし、`from`: 低めの `pitch`（例 `25〜35`）かつ手前寄り `center` → `to`: 高めの `pitch`（例 `65〜75`）かつ遠景を望む `center` / `zoom` へ遷移。
  - `ease: "smooth"`。
- **推奨尺・同期**：5〜8 秒。地形の規模感を語る発話、または章冒頭の BGM 盛り上がり（4 小節）に合わせる。
- **破綻パターンと回避策**：
  - `pitch` を上げすぎて地平線付近のタイル欠け・歪みが目立つ → `maxPitch: 85` まで上げず `65〜75` に留め、`sky` 設定と遠景タイルの描画を動画で確認する。
  - 手前に遮蔽する立体地形がない平坦地でチルトだけ行うと、ただ斜めになるだけでリビールにならない → 標高差がある場所でのみ使う。

### R9. 3D 統計ライズ＋フォーカス（コロプレス連動カメラ）
- **目的**：地域の統計差（人口・標高・被害額など）を平面の分布から立体の高低差へ滑らかに立ち上げて見せる。
- **向いている題材**：市区町村別の統計比較、人口密度・地価の集中、時系列の増減比較。
- **緩急タイプ**：静（平面確認）→ 穏（立体化＋注目）
- **MapLibre 構造**：
  - `from`: `pitch: 0`（平面で全体の境界と凡例を把握） → `to`: `pitch: 45〜55`, `bearing: ±15〜25°`（立体押し出しの奥行きを見せる）。
  - `ease: "smooth"`。
  - 連動：`choropleth` の `extrude: true` と `rise: [0.15, 0.55]` を `pitch` 起こしと同時進行させ、後半 `focus.window: [0.6, 1.0]` で注目地域以外を減光する。
- **推奨尺・同期**：5〜8 秒。前半で全体の傾向を述べ、後半のフォーカス点灯に合わせて具体値を読み上げる。
- **破綻パターンと回避策**：
  - 最初から斜め高ピッチにすると背後の小区域が柱に隠れて読めない → 平面または浅い角度から起こし、凡例・ラベルの重なりを確認する。

### R10. ビート・モンタージュ（無音テンポ導入・章予告）
- **目的**：動画冒頭のフックや章転換で、複数の地点・視点をテンポよく見せて期待感を作る。
- **向いている題材**：長尺動画の冒頭 5〜10 秒のプレビュー、複数地点を巡る特集の章予告。
- **緩急タイプ**：急（短尺・拍同期カットの連続）
- **MapLibre 構造**：
  - 1 カットあたり **1.5〜2.5 秒**（BGM の 2 拍または 4 拍の整数倍）で 3〜4 カットを連続させる。
  - 各カットは `ease: "out"` で 1 軸のみ短く動かす（例：短いプッシュイン、短いオービット、時代切替ロック）。
  - 隣接カット間で運動方向を揃えるか、意図的な「寄り→引き」の対比にする。
  - 各カットのテキストは 1 語〜短い見出しのみ（字幕や複数ラベルを詰め込まない）。
- **推奨尺・同期**：合計 6〜10 秒。BGM の小節頭にカット点をロックし、最後のカットで本編の R1（エスタブリッシング・ホールド）へ着地させる。
- **破綻パターンと回避策**：
  - 短い尺の中に大きな距離移動を入れてタイル読み込みや酔いが破綻する → 各カットの移動量を小さく抑え、読解が必要な情報は本編のホールド側へ送る。
  - 30fps で拍が微妙にズレてモタつく → 事前に `Math.round(beatSec * n * fps) / fps` でフレーム境界に揃えた `duration` を指定する。
