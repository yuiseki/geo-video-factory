# 3D 地形の表現設定と描画の制約

ショット JSON の地形パラメータ設定と、MapLibre 6.18.0 で 3D 地形を描画する際の仕様・トラブルシュート。

## 立体表現のパラメータ

ショット JSON のトップレベルで指定する。

```json
{
  "dem": "gsi",
  "exaggeration": 1.3,
  "hillshade": 0.25
}
```

### `exaggeration`（高さ強調）
- **既定値**: `1.3`
- **目安**:
  - **`1.3`（既定）**: 平坦すぎず嘘っぽくならない標準的な立体感。山岳、谷、火山、河川の解説に向く。
  - **`1.0`（等倍）**: 平坦な都市部（大阪・東京の運河や街区など）や、地上写真・建物の高さとの違和感をなくしたいとき。
  - **`1.5〜2.0`**: 日本列島〜広域ズームで山脈の起伏をわかりやすく強調したいとき。やりすぎると不自然な針状になるため `--stills` で確認する。

### `hillshade`（陰影起伏）
- **既定値**: `0.25`（`false` で無効化）
- **役割**: 空中写真（`seamlessphoto` 等）だけでは光の向きや凹凸が平たく見えるため、薄い陰影を足して地形の起伏を読み取りやすくする。
- **実装上の注意（`demshade` ソースの分離）**:
  - `page/flyover.js` では `terrain` 用の `dem` と `hillshade` 用の `demshade` を別々の `raster-dem` ソースとして定義している。MapLibre は同一の `raster-dem` ソースを地形と陰影で共有すると品質低下の警告を出すため。
  - 陰影色は `hillshade-shadow-color: '#0a1020'`、`hillshade-highlight-color: '#ffffff'` を既定としている。

## MapLibre 6.18.0 の地形描画における仕様と制約

### 1. ラベル・DOM 重ね物の投影タイミング
- `map.project([lng, lat])` は地形の標高を加味して画面座標を計算するため、**標高タイルと地図タイルが読み込み終わった後**に呼ばないと位置がずれる。
- `page/flyover.js` の `frame()` は地図の描画完了（idle）を待ってから DOM オーバーレイを配置している。順番を変えてはならない。

### 2. 地形上の `image` や `base` レイヤの切り替え
- MapLibre 5.24 では、地形有効時にラスタレイヤが**地形タイルごとのテクスチャとしてキャッシュ**され、ラスタの透明度（`raster-opacity`）や表示切り替えだけでは再描画されない挙動を確認した（`freeRtt` でも更新されなかった）。MapLibre 6.18.0 への更新後も、次の対策を含む実レンダリングが正常に完了することを確認している。
- そのため `page/flyover.js` の `frame()` では、ラスタ重ね物の透明度が前のフレームと変わったときだけ `map.setTerrain(null); map.setTerrain(terrainSpec);` で地形を入れ直している。
- また MapLibre 5.24 で `type: "image"` ソースが地形有効時に描かれない挙動を確認したため、画像を地形に貼るオーバーレイはカスタムプロトコル等を通したラスタタイルとして供給している。この方式は MapLibre 6.18.0 の実レンダリングでも動作確認済みである。

### 3. 空と霧 (`sky` / `fog`)
- `pitch` が **60 度より浅い**と空は画面に入らない。
- 遠景が白くかすみすぎる／境界が目立つ場合は、トップレベルの `sky` 設定で `fog-ground-blend` 等を調整する。

### 4. カメラとデータ範囲・描画負荷
- **GPU が必須に近い**: ソフトウェア描画（SwiftShader）では 3D 地形のメッシュ描画が極端に重く、`page.screenshot: Timeout 30000ms exceeded` が起きやすい。起動時の `webgl:` ログで GPU（NVIDIA 等）が使われているか確認する。
- **広域 × 高ピッチの負荷**: `zoom` が低いまま `pitch` を大きく倒すと、地平線付近まで大量の標高・写真タイルを読み込むことになり、`warning: N frame(s) were captured before all tiles loaded` やタイムアウトの原因になる。`zoom` を上げるか `pitch` を下げる。

## 地形関連のトラブルシュート

| 症状 | 原因と対処 |
|---|---|
| 海や国外に針のような山が立つ | 地理院標高の値なし（RGB `128,0,0`）を 0 m にしていない。`gsidem://` プロトコルを通しているか確認する。海外を映す場合は `"dem": "mapterhorn"` を使う |
| 海外の地形が真っ平ら（標高 0 m） | `"dem": "gsi"` のまま日本国外を映している。`"dem": "mapterhorn"` に切り替える |
| ラベルが地形とずれた所に出る | タイル読み込み前に `map.project()` している。`frame()` の待機順序を維持する |
| 地形上の `image` や `base` 切り替えが出ない | ラスタキャッシュの制約。`frame()` の `setTerrain` 再設定ロジックが動いているか確認する |
| `Timeout 30000ms exceeded` | SwiftShader になっているか、低 `zoom` + 高 `pitch` でタイル数が多すぎる。GPU 引数と `FLYOVER_GL` を確認し、カメラを見直す |
