# 素材別の取得手順と出典

動画で使う外部素材は、作者・取得先・ライセンス・加工内容を記録し、画面右下の `credit` / `credits` と概要欄の双方に残す。依頼ごとの指定素材がある場合はそちらを優先する。

## 1. いらすとや

- **点数上限**: 1 作品（1 動画）あたり **20 点まで**（商用・非商用を問わず規約の上限を守る）。
- **画像の取得**: 検索結果の `bp_thumbnail_resize("…/s72-c/<名前>.png", "<題>")` から URL を取り、`/s72-c/` を `/s600/` に差し替えると解像度の高い版を取得できる。
- **ショット JSON の指定例**:
  ```json
  { "type": "sticker", "src": "assets/irasutoya/ramen_moyashi.png", "screen": [1500, 400], "width": 280, "credit": "イラスト：いらすとや" }
  ```
- **出典表記**: `イラスト：いらすとや`

---

## 2. Wikimedia Commons

- **API での一括取得**:
  - `action=query&prop=imageinfo&iiprop=url|extmetadata&iiurlwidth=1200` を使い、画像 URL と同時にライセンス (`LicenseShortName`) と作者 (`Artist`) を取得する。
  - 取得したメタデータは作業ディレクトリの出典記録（`credits.json` 等）に残す。
- **ライセンスの優先順位**:
  - **CC0 / パブリックドメイン / CC BY** を優先して選ぶ。
  - **CC BY-SA** は派生物（動画全体）へのライセンス継承に関わるため、利用条件を確認したうえで避けられるなら避ける。
- **出典表記**:
  - `写真：<作者> / Wikimedia Commons (<ライセンス>)`
  - 例: `写真：City Foodsters / Wikimedia Commons（CC BY 2.0）`

---

## 3. EXPERIENCE JAPAN PICTOGRAMS

- **提供元**: 日本デザインセンター (`https://experience-japan.info/`)
- **利用条件**:
  - 商用無料、点数の制限なし、PNG / SVG で提供。
  - **形の改変は禁止**（色変更、拡大縮小、丸や四角で囲む装飾は可）。
  - アニメーション版を動画編集ソフトで再編集して使わない。
  - 素材 URL への直接リンク（ホットリンク）は禁止。手元にダウンロードして使う。
  - 規約は予告なく変わることがあるため、利用前に公式サイトの `/terms` を確認する。
- **出典表記**: 必須ではないが `素材提供：日本デザインセンター/EXPERIENCE JAPAN PICTOGRAMS` を入れる。

---

## 4. 立ち絵（VOICEVOX キャラクター等）

- **PSD はリポジトリに含めない**: 配布元から各自入手し、`tools/psd_sprites.py` で口・目の差分スプライトを書き出して使う。
- **規約の確認**: 東北ずん子・ずんだもんプロジェクトのガイドライン (`https://zunko.jp/guideline.html`) など、キャラクター・立ち絵作者ごとの規約とクレジット表記を確認する。

---

## 5. 過去の空中写真・地図画像

- 地理院タイルの年代別写真（`gazo1`, `ort_old10`, `ort_USA10`, `ort_riku10`）を接合して `image` / `panel` 素材にする場合も、元タイル・範囲・取得 URL・取得日を `manifest.json` 等に記録する。
- 地理院タイルはサーバー負荷を避けるため、取得範囲を必要な分だけに限り、多数を連続取得しない。
- 出典例: `出典：国土地理院 地理院タイル（空中写真、1945年〜1950年）を加工して作成`（`gazo1`〜`gazo4` は `国土画像情報（国土交通省）` を明記）。
