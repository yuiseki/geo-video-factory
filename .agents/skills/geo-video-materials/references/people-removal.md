# 実写真から人と車を消す

無人の街を見せたいが、実在の写真には人と車が写っている。生成画像を参照にせず、CC0 / CC BY の実写真を正本として残したまま、人と車だけを消す手順。実装は `packages/pipeline/people_removal.py`。

## 手順

1. マスク (ComfyUI と SAM 3.1 が動いていること)

   ```bash
   python3 -I packages/pipeline/people_removal.py mask <photo> <out_dir> [--url=http://127.0.0.1:8188]
   ```

   SAM 3.1 の文字指定の検出を 1 枚に 3 回かける。人、看板・画面、車。
   - 最終マスク = (人 − 広げた看板) ∪ 穴を埋めた車。
   - 看板と画面には人が写っていることが多い。看板の上の人を消すと看板の絵が壊れるため、人のマスクから看板を引く。
   - 車は看板で守らない。ラッピング車は画面として検出されることがあるため。車の輪郭の内側の抜けは埋める。
   - 看板の指定に `poster` と `signboard` を入れない。ラッピング車に当たった。
   - 誤検出を領域ごとに落とす。夜の街の写真で実際に起きたもの:

     | 誤検出 | 落とす規則 |
     |---|---|
     | 看板の絵を人と検出し、看板の外にはみ出した縁が残る | 半分以上が (広げた) 看板に重なる人の領域は丸ごと落とす |
     | 曲面の看板をバスの側面と検出し、看板が消えた | 7 割以上が看板に重なる車の領域を落とす |
     | 屋上近くの光の帯を車と検出 | 下端が画面の上 4 割より上にある車の領域を落とす |
     | 見上げた高層ビルをバスの正面と検出し、ビルが丸ごと消えた | 上端が画面の上 1 割に届く車の領域を落とす |
     | 同じビルの下半分を人の群れ (`crowd`) とも検出した | 半分以上が上の規則で落とした車の領域に重なる人の領域を落とす |

     画面の上端に届くことだけを理由に人の領域を落とすと、カメラのすぐ前を通る人や、俯瞰写真の奥の歩行者が残った (試して戻した)。2 つの別の指定 (車と人) が同じ所を指したときだけ建物とみなす。
   - 最後に写真の長辺の 1.2% だけ広げてぼかす。夜の写真は人の動きのぶれが輪郭の外まで残るため。

   SAM に送る画像は 3840×2560 の画素数 (`SAM_MAX_PIXELS`) までに縮める。3840×5760 の縦長の写真をそのまま送ると、GPU (MPS) のメモリが足りずに止まった。返ってきたマスクは写真の大きさに戻す。

   SAM の生の層 (`_people`, `_signs`, `_vehicles`) を保存するので、組み合わせの規則を変えたときは `remix <out_dir> <id> ...` で検出をやり直さずにマスクを作り直せる。

2. 塗り (torch と spandrel のある環境。ComfyUI の venv で動く)

   ```bash
   <comfyui-venv>/bin/python -I packages/pipeline/people_removal.py fill big-lama.pt <out_dir> <photo> <mask_grown> ...
   ```

   LaMa (`big-lama.pt`, Apache-2.0) を長辺 1024 px までで全体にかけ、ぼかしたマスクで元の写真に重ねる。マスクの外の画素は元のまま。

## 選んだ理由と、やめた方法

| 方法 | 結果 | 判断 |
|---|---|---|
| SDXL inpaint を 1536 px の切り出しにかける | 無い看板、縞の塊、雨を描き足した | やめた。実写真を正本にする方針に反する |
| SDXL inpaint を小さな区画ごとにかける | 区画の継ぎ目が四角く見え、1 枚 15〜20 分かかった | やめた |
| ComfyUI の LaMa ノード (`comfyui-inpaint-nodes`) | 内部で 256 px に縮めるため、塗りがぼやけた | 使わない |
| LaMa を直接、長辺 2048 / 1536 px で | 大きな穴で周りの模様を縞状に繰り返した | やめた |
| LaMa を直接、長辺 512 / 768 px で | 車や人の塊のような影が戻った | やめた |
| LaMa を直接、長辺 1024 px で | 物を描き足さず、縞も少ない。1 枚数秒 | 採用 |
| 車の領域だけ下へ画面の高さの 5% 広げる (車の影を塗りに入れる) | 手前の車の跡の黒いしみは変わらなかった。しみは影ではなく LaMa の塗りそのもの | やめた |

LaMa の限界: 人の群れや車のような大きな穴は、なめらかでぼけた路面になる。じっと見ると分かる。動画では手前の大きな穴の写真を避けるか、そこに別の素材 (看板の差し替え、光) を重ねる。

## 検品

- 消した後と元の写真、マスクを並べた一覧を作り、1 枚ずつ見る。
- 見る点: 人の残像 (ぶれの跡)、看板や画面の中の人が消えていないか、車の一部が残っていないか、描き足された物がないか、大きな塗りのぼけ。
- マスクの被覆率 (`mask coverage`) が 0.3 を超える写真は、塗りの面積が大きく、ぼけが目立ちやすい。
- ヘッドライトを点けた遠くの車は、残ることがある。SAM が同じ車を車としても看板・画面としても拾い、「7 割以上が看板の車の領域は落とす」規則で落ちるため。看板の領域と車の領域の面積比、高さで分けようとしたが、看板 (道頓堀の縦の看板、交差点の下端の電飾) にも同じ値のものがあり、分けられなかった (11/23)。残った車は、目で見つけて手でマスクに足す: 作品の場所に `{"<id>": [[x0, y0, x1, y1]]}` (写真に対する割合) の JSON を置き、`remix <out_dir> <id> --add=<json>` でマスクを作り直してから塗る。出力は新しい版の場所へ。id は写真の名前の頭 3 文字なので、別のフォルダの写真と重なるときは `"<写真のフォルダ>/<id>"` をキーにして `--folder=<写真のフォルダ>` を付ける。
- 白い車 (バン) が看板・画面と読まれると、その前を歩く人も「看板の中の人」として落ちる。店のガラスの中の人も、画面として守られて残る。どちらも箱で囲んで消す。ガラスの中を消すと店内は柔らかくぼける (11/23)。
- 俯瞰の写真では、遠くの車は画面の上の方 (高さの 4 割より上) に写る。「下端が高さの 4 割より上の車の領域は屋上近くの光の帯として落とす」規則で落ちて残る (258 の駐車中の車)。俯瞰は箱で足す。箱が木などにかかると、そこもにじむので、車だけを小さく囲む (11/23)。
- 車の跡の黒いしみ (塗りが車の影の暗さを拾ったもの) も、しみ自体に箱を足して塗り直すと消える。車のマスクを機械的に下へ伸ばす方法では消えなかったが、しみを見て囲むと消えた (11/23, 305 と 139)。
- 人の残像が、マスクの内側の塗りのむらとして出ることもある (路面と店先が重なる所)。これは検出漏れではなく LaMa の塗りの限界で、箱を足しても直らない。

## 看板の面を差し替える (試作)

人を消した写真の看板を、文字のない自前の絵に替える。

```bash
python3 -I packages/pipeline/sign_regions.py <out_dir> <id> ...   # SAM の看板の層から 4 隅 -> <id>_signs.json
python3 -I packages/pipeline/sign_replace.py <photo> <out_dir>/<id>_signs.json <out.png>
```

- `sign_regions.py` は、看板の領域ごとに端の 4 点 (左上、右上、右下、左下) を取る。`fill` (領域の面積 ÷ 4 隅の四角形の面積) が 0.8 未満のもの、三角形のように 4 隅が取れないものは `skipped` に分ける。
- `sign_replace.py` は、元の看板の大まかな色を残し、細部 (文字、顔、ロゴ) を決まった模様に替える。

夜の交差点の 8 枚にかけた結果 (2026-11-22)。自動のままでは使えない。
- 曲面の大型画面は一部しか検出されず、半分だけ替わる。
- 店先や建物の一部まで看板と判定され、灰色の板になる。
- 縞や水玉の模様は、光る看板ではなく仮置きの箱に見える。

使うときは、`<id>_signs.json` から替える看板を人が選び、4 隅を直してから流す。絵は別に作る。
