# 位置合わせだけに使う写真 (CC BY / CC BY-SA)

映像に貼る写真 (建物の壁のアトラス、地面、写真マーカー) は CC0 と Public domain だけにする。CC BY と CC BY-SA の写真は、オプションを付けたときだけ集め、SfM などの位置合わせの補助にだけ使う。映像にはその画素を一枚も入れない。

## なぜよいと判断したか

- CC BY 4.0 と CC BY-SA 4.0 の帰属表示と継承の義務は、作品か翻案物 (Adapted Material) を公衆に提供 (Share) するときに生じる (第 3 条)。写真を手元で解析すること、特徴点を取り、照合し、バンドル調整に使うことは、どちらのライセンスでも許されている。
- 翻案物とは、元の作品に由来し、著作権者の許諾が要る形で改変したもの。位置合わせから外に出すのは、CC0/PD の写真の撮影位置・向き・内部パラメータという、実世界の幾何の数値だけ。写真家の創作的な表現は残らない。計算の途中で写真に依存したことと、翻案物にあたることは別の問題である。
- 日本の著作権法 30 条の 4 (表現を享受しない情報解析) にもあたる見込みが高い。江差追分事件 (最高裁 2001-06-28) は、依拠していても、共通するのが事実やアイデアだけなら翻案ではないと判断している。ただし今回は CC のライセンス自体が手元での複製と改変を許しているので、30 条の 4 だけに頼る必要はない。
- この具体的な SfM の使い方についての判例や公式見解は確認していない。写真の配布元の API 規約、データベースの権利、国ごとの Public domain の扱いは別に考える。

## 中間生成物の扱い

| 生成物 | 扱い |
|---|---|
| CC0/PD の写真のカメラの位置・向き・内部パラメータ | 後段に渡してよい |
| 特徴点の座標、記述子、色の無い点群 | 手元でだけ使う |
| 色付きの点群 (COLMAP の `points3D` は RGB を持つ) | 映像にも外にも出さない |
| BY / BY-SA の写真で塗ったアトラス、色補正、穴埋め、3DGS の学習 | 作らない |

## 仕組み (`packages/pipeline`)

| 工程 | 何をするか |
|---|---|
| 収集 | `cc0_photo_collector.py collect --license-mode=registration --registration-only` のときだけ BY と BY-SA を集める (NC と ND は集めない)。どちらかを欠くと止まる。行には `"use": "registration"` が付く |
| 置き場 | `photo_store.put` は、その行を `registration-<source>:<id>` という別の参照で、別の置き場 (`photos/registration-<source>/`) に入れる。CC0/PD の参照では見つからない |
| 位置合わせ | `atlas_before.py photos --registration` が、場所の `<名前>_registration_manifest.json` の写真も SfM に入れる。`world` は、位置合わせ用の写真のカメラを外してから後段に渡す |
| 塗る | `build_atlas` は、カメラの写真ごとに `photo_use.check_paint` を通す。置き場の記録が CC0/PD 以外か、位置合わせ用の参照なら、そこで止まる |
